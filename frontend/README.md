# Frontend — 农业模型助手

Next.js 16 (App Router) + TypeScript + Tailwind 4 + shadcn/ui。

## 本地启动

内部账户登录后，聊天侧栏自动加载该账户的服务器历史会话，支持刷新恢复、重新登录和续聊。
超过一页可点击“加载更早的对话”，账户会话不受游客的 10 个临时会话限制。
游客会话仍保留在当前页面；上传附件沿用临时有效期，历史问答保存不代表附件长期可用。

```bash
# 安装依赖
pnpm install

# 复制环境变量示例
cp .env.local.example .env.local

# 启动开发服务器（Turbopack）
pnpm dev
```

打开 <http://localhost:3000>，输入问题后查看带引用的回答。
可在同一个输入框附加 WHCNS 氮/水平衡输出表，查询字段极值和日序；也可上传
`.txt/.md/.pdf/.doc/.docx` 文档，在本条消息中引用其中的文字。单会话最多 10 份文件，
文件卡片横向滚动。结果表分析需要后端 `model-tools` extra，文档问答需要 LLM。
附件绑定到本条消息，点击发送后立即清空输入区的附件，消息记录保留已发送的文件名。下一条消息默认不带上轮文件，只有用户再次上传才会附加；失败重试和“重新回答”继续使用原消息的附件。新建或切换对话保留各自尚未发送的附件。对话超出历史上限被移除、离开聊天页面、刷新或关闭页面时释放文件；尚有后台任务的对话保留服务器文件租期，避免中断其执行。活动页面为全部保留对话的附件定时续期，失联文件由后端清理。
本条消息待发送的附件按内容 SHA-256 去重（包括改名副本），相同文件自动跳过并提示；已发送的文件可以再次上传用于新消息。平时只展示文件名与上传状态，失败时显示原因。
可带着附件直接问文献，也可问“硝态氮最大值是多少，为什么可能这么高？”；
组合链路部分失败时显示“部分完成”，保留已得到的结果。
回答支持 Markdown 表格、代码及复制；正文完整展开，文献和文件依据默认折叠。文献按篇去重，展示实际引用的文章标题、作者和年份，原文片段及正文字符定位不对客展示。编号按正文首次出现顺序从 1 开始，未引用的检索候选不展示；点击正文引用可展开并定位到对应文献。原文支持弹窗预览和下载，缺失时明确提示；复制成功后按钮变为“已复制”，1 秒后恢复“复制回答”，失败时明确反馈。

文献引用优先透传后台文献库当前记录的题名、完整作者署名和年份；历史 PDF 按内容指纹关联文献库，无关联记录时回退到 `data/papers/catalog_m16.json`。确实缺失的字段显示“暂缺”。后端 `/api/documents/{document_id}` 提供已关联的本地 PDF，`?download=true` 使用下载响应；PDF 不随代码入仓，部署时需要保留原文目录。
输入框支持拖放多个附件和上传进度；Enter 换行、Ctrl/Cmd + Enter 发送，兼容中文输入法。
等待时显示耗时，失败后可以重试原问题；“新对话”创建独立上下文，原对话可从历史列表切回并继续提问。
后端支持 `chat-runs-v1` 时，提问先建立归属身份、再用稳定轮次和提交标识受理。前端轮询实际步骤，处理过程仅在本轮答案尚未加载出来时显示，答案出现后移除；断网后自动查询原运行，持续断网则允许手动重试查询。确认失败、中断或完成后的“重新回答”才创建新运行，保留原输入和首轮关联。恢复默认有效 24 小时，过期后需新建对话。后端仅有旧接口时兼容原同步模式。
未完成请求的提交标识与必要输入按账号暂存于当前标签页会话存储，刷新后只查询原运行，不自动新建任务；窗口最大 24 小时，服务端仍校验归属与实际有效期。完成后的普通历史仍保存在内存；跨窗口历史、用户取消和逐字流式输出未开放。最新实现与验证见 [1017 PRD 开发交付](../docs/iterations/2026-10-17-prd-completion/README.md)。
V2.1 在当前聊天页面内最多保留 10 个对话（含当前对话），按创建时间从新到旧固定排列，切换会话和继续聊天不改变列表顺序。历史会话位于左侧栏：电脑端默认展开、可收起，手机端默认隐藏、点击左上角图标打开；手机端选择或新建后自动关闭，也支持点击遮罩或 Escape 关闭。
界面不常驻展示数量上限或存储范围说明，只有创建超限对话时才提示，并移除最早创建且没有待确认运行的对话；提示数字使用统一容量配置。输入框随内容和可用宽度自动调整高度。
消息、回答依据、已发送附件记录、待发送附件、输入草稿和失败重试状态随对话保留；未发送的草稿或附件也可保留，重复点击“新对话”不会创建多个空白记录。
等待回答、上传或准备示例时可以新建对话、切换和操作历史会话；各会话独立处理任务，回答、进度、错误和附件只回到原会话。侧栏显示仍在处理的会话，正在处理的会话不会因达到数量上限而被移除。同一会话的原请求完成前不重复发送新问题。普通历史保存在页面内存，刷新、关闭、离开聊天页面或切换登录身份后清空；未完成请求单独保留恢复信息，刷新后逐会话恢复。本期不提供跨窗口或账号历史同步。
健康检查使用开发工具访问 `${NEXT_PUBLIC_API_BASE_URL}/api/health`，普通界面不展示调试信息。

`/evaluation` 登录后直接打开会话审核，默认待审核。你和协作者可看完整会话，一键通过、按轮标记问题、补充复核意见，并在原会话旁查看修改后的验证回答。单人审核即可通过，不要求分层评分或专家分派。原附件不足时需在前台补传后手动确认。

主导航保留运行记录、文献管理、案例与措施、星标问题和 Prompt 迭代。标签、能力、线上看板和历史测评入口收在“更多工具与历史记录”；旧数据与链接保留。文献摘要和结论常显，原文对照及人工标签修改继续使用。详见[轻量审核说明](../docs/iterations/2026-10-18-lightweight-review/README.md)。

## Skill 能力与有限配置

登录工作台后，在“更多工具与历史记录”点击“Skill 能力”，或进入 `/evaluation/skills`，查看七项实际注册能力的用途、示例、输入输出和使用边界。支持中文名称或标识搜索；详情默认展示业务说明，Schema 和当前版本可展开。

开发者、测试者和领域审核人都可查看。状态读取不会执行模型请求；已初始化但未验证的远程模型显示“依赖待验证”，材料缺失和解析格式依赖分别说明。页面支持刷新状态和失败重试，仅案例解释支持表达风格、详细程度与组织方式三个枚举配置；保存、恢复默认和并发冲突均由服务端校验，已受理运行保留原快照。其他能力只读。运行记录的工具明细可跳转当前能力说明，历史事实仍以原运行版本为准。

后端目录与详情仍使用认证 GET，表达配置通过独立的 configuration 接口读取、保存和恢复默认。线上看板收在“更多工具与历史记录”；Prompt 迭代有独立导航，文献全文同步位于文献详情。Prompt 迭代保留原 `/evaluation/explanation-trials` 路由：左侧选历史版本，右侧可新增或选历史版本，同题对比回答；版本可独立保存，并选择一个已保存版本全局生效，不展示逐题评价。详见 [Prompt 版本与全局表达](../docs/iterations/2026-10-17-prompt-iteration/README.md)。正式会话审查模块已移除，旧链接转到运行记录；会话与每轮执行明细统一从运行记录查看，后续 harness 沿会话维度扩展。线上看板以完整会话为主视角，展示会话数、多轮占比、平均轮数、会话状态与轮数分布；每轮运行和调用统计用于下钻。时间按会话首次受理选择，模式、版本、Skill、任务条件在同一轮命中后保留该来源下的完整会话，跨日追问归属原会话，重跑另计。开发者可从当前范围的会话进入完整运行记录。指标不代表回答质量或上下文理解正确性，也不提供原模块的人工审查指标。实现与验收见 [会话看板口径](../docs/iterations/2026-10-17-session-dashboard/README.md) 和 [1017 PRD 开发交付](../docs/iterations/2026-10-17-prd-completion/README.md)。

## 启动 chat 完整闭环（M1.3 起）

前提：后端启用 RAG，并已建好向量索引。

```bash
# 1. 后端：装 rag extra
cd backend && uv sync --extra rag

# 2. 后端：建索引（首次或资料更新时跑）
uv run python scripts/index_papers.py \
    --paths ../data/papers/sample.txt \
    --persist-dir var/chroma --collection papers --repo-root ..

# 3. 后端：backend/.env 设
#    DEEPSEEK_API_KEY=sk-...
#    RAG_ENABLED=true
#    RAG_CHROMA_DIR=./var/chroma

# 4. 后端：启动
uv run uvicorn src.main:app --reload

# 5. 前端
cd ../frontend
cp .env.local.example .env.local
pnpm dev
```

## 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 错误条 `请求未发出…`（code=`network`） | 后端未启动 / 端口不通 / VPN 拦了 localhost | 检查 `uvicorn` 是否在跑；樱花猫 VPN 把 `127.0.0.1` 加 ByPass |
| 503 + `rag_not_configured` | 后端 `.env` 没设 `RAG_ENABLED=true` | 改 `.env` 后重启后端 |
| 503 + `rag_query_failed` | chroma 索引目录不对或为空 | 重新跑 `scripts/index_papers.py`，确认 `RAG_CHROMA_DIR` 路径正确 |
| 502 + `llm_unreachable` | DeepSeek 不可达 / 代理设置 | 检查网络与 `DEEPSEEK_BASE_URL` |
| 422 + `输入校验失败` | query 为空白 / 超 1000 字 | 调整输入；前端字符计数变红时已禁用提交 |
| 首次回答等待较长 | BGE 嵌入模型冷加载或模型响应较慢 | 等待区显示已用时间及较长等待提示 |

### 工作台账号登录 V1.0

本机账号凭据：`backend/var/eval/account-credentials.txt`。当前标签页窗口内，前台与工作台共享登录，切换和刷新均会恢复身份；退出会撤销服务端会话。窗口定期续期，关闭后不跨独立窗口保留凭据。历史身份与角色权限保持不变。详见 [前后台共享登录 V1.1](../docs/iterations/2026-10-13-workbench-login/shared-session-v1.1.md)。

隔离工作台浏览器测试需设置 `EVAL_TEST_USERNAME`、`EVAL_TEST_PASSWORD`，测试不再读取正式密钥。新增 `evaluation-accounts.spec.ts` 使用 `ACCOUNTS_TEST_API` 指向 `tests.accounts_fixture`，所有写入均落在 `ACCOUNTS_TEST_ROOT` 临时目录。
