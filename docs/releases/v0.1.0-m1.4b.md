# Release Notes - v0.1.0-m1.4b

Release date: 2026-05-18

Tag target: `main` after M1.4-b reranker evaluation and delivery cleanup

## Summary

`v0.1.0-m1.4b` marks the first deliverable end-to-end RAG Agent prototype.
The project now has a working engineering skeleton:

```text
PDF/text corpus -> ingest -> chunk -> embed -> Chroma -> retrieve -> rerank
-> prompt context -> LLM -> /api/chat -> frontend Chat UI -> citations
```

This is a foundation release, not a claim of high professional answer quality.
M1.4-b passed the retrieval-level DoD, but failed the answer-level demo
threshold.

## Included

- FastAPI backend with `POST /api/chat` and structured error handling.
- Next.js single-turn Chat UI with loading, error states, health debug, and citations.
- Local BGE embedding path and Chroma persistent index.
- Real 8-PDF corpus baseline with 1348 chunks.
- `BAAI/bge-reranker-v2-m3` integration behind `RAG_RERANKER_ENABLED`.
- Retrieval debug script that can dump embedding-only or reranked top-N results.
- Mini eval runner and manual judgement YAML workflow.
- M1.3.2, M1.4-a, and M1.4-b report/review documentation.

## Quality Results

| Metric | Result |
|---|---|
| Corpus | 8 PDFs / 1348 chunks |
| M1.4-a baseline run | `20260507-164315` |
| M1.4-b reranker eval run | `20260512-113851` |
| M1.4-b retrieval debug run | `20260512-103608` |
| HTTP errors | 0 / 10 |
| q01-q08 expected source in reranked top5 | 7 / 8 |
| `usable_for_demo` | 2 / 10 |
| Refuse `not_hallucinated` | 2 / 2 |

Conclusion: the reranker improves retrieval and citation grounding, but the
answer-level quality remains below demo threshold. The remaining bottleneck is
evidence extraction, numeric fact recovery, and multi-source synthesis.

## Not Included

- Multi-turn chat history.
- Streaming responses.
- Markdown/math rendering.
- Citation click-through to original PDF spans.
- WHCNS simulation execution.
- Query rewrite or source-aware context packing.
- Larger 20-50 question evaluation set.
- Production deployment.

## Delivery Positioning

This release can be delivered as:

- an end-to-end RAG engineering prototype,
- a reproducible thesis/project milestone,
- a curated demo showing chat, retrieval, reranker diagnostics, citations, and refusal behavior.

It should not be presented as:

- a reliable agronomy expert QA system,
- a production decision support system,
- evidence that answer quality has reached the HR/demo target.
