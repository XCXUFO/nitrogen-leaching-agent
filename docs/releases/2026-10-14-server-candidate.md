# 2026-10-14 服务器更新候选版

目标：沿用已有服务器部署，发布当前聊天、文献库、账号及案例库功能。本次不是重新搭建服务器。

## 上线前小修

- Next / eslint-config-next 从 16.2.4 更新至 16.3.8，更新有公告命中的传递依赖；shadcn CLI 移入 devDependencies。生产依赖在线审计为 0 条告警，不代表所有代码已经经过安全审计。
- Next API rewrite 等待上限为 300 秒；聊天处理总上限为 240 秒。LLM 调用另有包含 SDK 重试的整体期限（默认 190 秒）。超时会取消异步调用、释放会话锁，并返回可识别的错误。同步计算线程不能由此强制终止。
- 启用 RAG 时，启动阶段验证非空索引并执行一次本地检索，覆盖 embedding、索引维度及启用的 reranker。失败时不创建知识服务，`/api/ready` 返回 503；不会为健康检查调用收费 LLM。
- 本地交付启动器等待 `/api/ready`，禁用代理头解析，避免直接访问 Next 的调用方伪造 IP。生产入口需要核对现有 Nginx→后端链路，参见 [公开部署配置](../public-demo.md)。

## 现有服务器更新步骤

1. 确认实际 Git 分支、工作目录、服务名、构建目录和 Nginx 路由，记录当前提交和回滚方式。只有本候选版完整提交并推送后，服务器 `git pull` 才能取得所有新功能。
2. 备份服务器配置、登录配置、运行/案例/文献/预算数据库与 PDF。保留原有模型及 Chroma 索引；不要把本机 `.env`、数据库或示例账号覆盖到服务器。
3. 将完整源码版本送至服务器，同步后端锁定依赖（包括已有启用的 rag、model-tools extras）、前端 `pnpm install --frozen-lockfile`，使用实际构建目录执行 `pnpm build`（已固定为 Webpack）。先在候选目录完成构建，再切换现有服务，避免覆盖正在使用的静态资源。
   若服务器仍使用 10 月 7 日的密钥账号配置，必须先检查身份格式，再用 `backend/scripts/create_eval_accounts.py --directory 实际账号目录` 迁移，取回私有凭据后登录；新前端不再提供旧密钥输入。已有用户名账号不能重复初始化。新增文献/案例库为空时，不应自动拿本机验证库覆盖；需要保留的正式内容应单独备份迁移。
4. 服务器 `DEEPSEEK_PROXY` 留空；核对服务环境没有覆盖回本机代理。外层代理读取超时至少为 300 秒；同机 Nginx 直连后端时覆盖 X-Forwarded-For 为真实连接地址，Uvicorn 只信任该 Nginx 地址，保持单 worker。
5. 重新生成与新构建匹配的交付清单（若现有部署使用清单启动），沿用原进程管理器重启；验证 health、ready、登录、文献列表、案例库和一次真实问答。启动失败时回退上一目录/配置，不删除持久数据。
