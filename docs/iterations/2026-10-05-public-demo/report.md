# 公开 Demo 功能改造记录

目标：用于简历的长期公开网址；访客可真实体验 C 端、免登录浏览后台，但不能修改评测数据。

## 实现

- C 端：一键加载真实 Nbal 示例，走原上传/计算流程；最小值追问建议；能力范围、历史案例入口、超限与异常回退。
- 展示后台：`/showcase` 与模块/详情 URL，免登录、桌面侧栏、手机横向导航、搜索分页、原文摘录及运行追踪；原 `/evaluation` 管理登录保留。
- 数据隔离：公开 API 仅提供明确选定的 JSON 快照和单份示例，完全不查询正式评测库。4 个历史能力案例、1 个合成流程演示，共 9 个不同 Run。真实历史运行没有冒充专家评分，合成 fail/pass 在列表和详情中标注。
- 公开保护：签名 HttpOnly 访客 Cookie、会话命名空间、附件所有者校验、来源/体积检查、分钟限制、并发限制、SQLite 持久化每日聊天额度和模型输出 token 上限。须开启 `PUBLIC_DEMO_ENABLED`，单 worker 部署。
- 同源 API 转发及生产配置说明，避免外部浏览器访问自己的 localhost。修正已有 sans 字体变量自引用。

实现方式为独立公开投影，不给访客签发管理凭证，也不改变原三种管理角色。公开展示对象均经过选取；新增访客聊天只进入私有运行库，不会自动公开。
