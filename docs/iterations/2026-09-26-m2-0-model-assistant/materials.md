# WHCNS 最小资料包与审核登记

状态：待收集／待审核。现有论文目录不能替代模型手册、版本说明或真实输入输出。
此文件是资料登记模板，不含已确认的模型参数、范围或案例事实。

## 最小资料包

| ID | 材料 | 最少需要确认 | 当前状态 |
|---|---|---|---|
| whcns-version | 版本与说明材料 | 模型名称、版本/构建号、说明文档及对应关系 | 待提供 |
| whcns-inputs | 输入规范 | 字段含义、单位、必需条件、缺失值处理、格式 | 待提供 |
| whcns-case-input | 一个完整案例的输入 | 案例背景、输入文件、情景与模型版本 | 待提供 |
| whcns-case-output | 同一案例真实输出 | 对应运行、输出文件、字段含义、预期可核对数值 | 待提供 |
| whcns-limitations | 错误与限制 | 常见错误、适用范围、不能得出的结论 | 待提供 |
| whcns-permission | 使用与展示许可 | 毕设、演示及公开访问分别允许哪些材料 | 待确认 |

项目负责人联系同门并填写；尚未发送邀请，也未获得授权或完成专业审核。
未确认可公开的材料不提交仓库，不放入公开评审页面。

## 每份来源的统一登记字段

| 字段 | 内容 |
|---|---|
| source_id / source_type | 稳定标识；paper / manual / case |
| title / year / version | 真实标题、年份、文档版本；未知留空并说明 |
| model_id / model_version | 对应模型及版本，不以论文年份推定版本 |
| location / checksum | 文件位置或正式来源链接、文件校验和 |
| locator | 页码、章节或表格位置；PDF 页序与印刷页码区分 |
| provided_by / provided_at | 提供者与日期 |
| usage_permission | 允许使用与展示范围、确认依据；未确认标记 pending |
| review_status | pending / reviewed / needs_revision |
| reviewed_by / reviewed_at | 审核者、日期及具体审核范围 |
| supported_claims / limits | 支持哪些解释及不能支持哪些结论 |

模型档案按用途、适用条件、输入、输出、常见错误、结论限制逐项引用上述来源。
整份资料通过审核不代表所有派生解释都已审核。

## 真实案例选择

优先一套版本明确、输入输出齐全、可以解释且允许展示的案例。
登记 case ID、背景、目标、模型版本、输入/输出文件清单与哈希、运行来源、
审核者及审核日期。由同门确认哪些数值应一致、哪些差异可以解释以及理由。

工具选择：**待材料确认**。输入格式稳定时选输入检查；输出更完整时选结果表读取。
在确定前不同时实现两条流程，也不编造格式、单位或专业阈值。
