# 单一对话窗口：WHCNS 文件闭环实施记录

日期：2026-09-28。基线：`399b130`。改动位于当前项目工作区，未提交或推送。

## 本轮实现

- README、架构 ADR-008、M2.0 spec 与试评任务已同步单一对话定位。
  不再规划三个产品入口、教学流程或普通用户评审页面。
- 原聊天输入增加 WHCNS 氮/水平衡表上传、当前附件展示、更换和移除；
  清空对话会清空客户端附件引用，后端摘要按到期时间清理。
- `POST /api/files` 接收原始字节；按文件内容识别 XLS/XLSX，校验表名、字段、单位、
  有限数值和连续日序。扩展名与内容不一致仍按真实格式读取。
- `POST /api/chat` 增加可选 `file_id`，返回 knowledge / file / clarification 分流结果。
  原 RAG、历史、引用和错误契约保留。文件计算不调用 LLM，也不运行 WHCNS。
- 文件问题仅支持明确字段的整表最大/最小值与模型日序。采用有限语句规则，
  额外指标、浓度、时段、总量、解释等未识别要求保留为追问，避免只回答部分要求。
- 独立 `file_evidence` 返回文件名、SHA-256、字段、单位、计算范围、
  值与日序单元格、并列数量、工具与规则版本。并列时展示首次出现。
- 普通界面移除健康探针、session、检索分数和错误代码；用户仍能看到必要错误原因。

## 文件生命周期

10 MiB 上传上限；最多同时解析 2 份，展开归档不超过 100 MiB，单元格不超过 500,000。
临时原件解析后删除，摘要仅保存在单进程内存，最多 32 份，有效 30 分钟。
刷新、到期或后端重启后需重新上传。随机 token 是临时访问凭据；
没有持久任务状态、用户鉴权或跨 worker 共享。当前使用单个后端 worker。
原始材料没有加入 Git，没有发送给 LLM，没有执行 WHCNS.exe。

## 演示步骤与剩余范围

1. 后端安装 `model-tools` extra，单 worker 启动；知识问答另需原 RAG/DeepSeek 配置。
2. 打开聊天页面，附加 `Nbal_out.xls`，等待检查成功。
3. 输入“硝态氮淋失最大值及对应日序”，核对上表结果与文件证据。
4. 输入“leak_NO3 最小值”可复用当前附件；模糊问题或季节总量会说明范围并追问。
5. 移除附件后，原文献知识问答继续使用 RAG。

手册逐页文本尚未接入检索；标题、页码、版本、审核状态的检索引用是下一步。
时间子集、多指标分析、季节总量、日期换算及通用自然语言编排未实现。
专业字段语义、模型版本、输入输出配对、展示许可仍待确认，不能宣称案例复现完成。
