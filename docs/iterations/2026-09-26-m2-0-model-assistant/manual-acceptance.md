# 单一对话窗口人工核验单

日期：2026-09-28。状态：**全部待人工执行**。本单针对当前项目工作区，不能用旧服务或旧部署的结果代替。

## 核验目的与已有验证

自动测试和接口层真实文件核对已经完成，前端 lint/构建已通过。人工核验补足：
浏览器能否实际完成流程、真实 RAG/LLM 是否可用、上下文是否正确、引用是否支持结论、
错误与限制是否能被理解。自动测试通过不等于全部产品能力已验收，也不代表专业正确性全部确认。

本轮不验证在线运行 WHCNS、案例复现、自动施肥决策或手册专属检索；这些能力未交付。

## 两条链路的多轮边界

| 链路 | 当前支持 | 当前不承诺 |
|---|---|---|
| 知识问答 | 传入最近最多 12 条消息（用户和助手合计，约 6 组问答）；后端进一步按字符预算截取，用于检索和指代理解 | 无限记忆、跨刷新恢复、每种指代都正确；事实仍要核对本轮证据 |
| 文件分析 | 当前附件在页面内持续复用；每问明确字段和最大/最小值即可连续查询 | 不使用历史消息继承上一字段；“那最大值呢”应追问；不将工具和 RAG 自动组合成混合回答 |

因此不能笼统地把两条链路都称为完整多轮理解。文件链路目前是附件复用加显式查询。

## 开始前

- 确认前后端运行当前工作区版本，打开前端页面（默认 http://localhost:3000）。
  如尚未启动，参照仓库 README；知识测试须启用本地 RAG、可用索引和 DeepSeek 配置。
  本单不表示服务此刻已经启动，不打印或收集 API key。
- 后端使用单 worker。若知识服务提示未配置，将相关项记为“受阻：环境”，不要算通过或直接认定代码缺陷；文件链路仍可单独核验。
- 记录日期、浏览器、前后端地址、代码版本/工作区标识。当前改动尚未提交，单写基线 commit 不能唯一表示本次代码。
- 原始材料只读；另开 Excel/LibreOffice/WPS 核对单元格，不保存改动。
- 必做项约 30–45 分钟，资料核对较慢可延长。到期项另需超过 30 分钟，不作为必须等待的前置条件。
- 每条用“通过 / 不通过 / 受阻 / 待执行”记录；体验问题另外记录，不能把未执行项勾为通过。

## 执行规则

按下列顺序操作。K01–K03 保持同一对话；F02–F05 保持同一附件；每项的重传、清空要求优先。
允许答案有正常措辞差异；数值允许显示舍入，例如 3.659263849 或 3.65926，误差应与显示精度一致。
单位、文件、模型日序和单元格必须准确，不接受用四舍五入解释错行错列。
只看到引用列表不等于证据正确：至少核查一条关键结论的原文、对象和条件是否一致。
短引用片段不足时打开对应论文；拿不到原文则该证据核验记“受阻”，不要自行认定通过。

## 本轮验收结论怎么判

1. **文件核心流程通过**：F01–F07 全部通过，数值、单位、日序、单元格无错误；异常输入不产生虚构结果。
2. **知识链路通过**：K01–K03 全部通过；至少有一次实际 RAG/LLM 成功回答，关键引用人工核对成立。仅“服务未配置”或持续“无资料”不能算链路验收通过。
3. **浏览器交互通过**：A01、B01–B04、X01–X04 全部通过。受阻项不能等同通过，应恢复条件后重测。
4. **补充覆盖**：O01–O03 独立记录；未做时明确标注未验证，不把主流程通过写成所有错误场景通过。
5. **当前限制可接受**：F05 的省略式追问、X01 的附件优先分流、X03 的刷新丢失状态是已知限制；行为符合说明可判本项通过，同时记录对实际使用的影响。不能据此声称已解决完整多轮或持久化需求。

数值错误、证据错配、使用错误文件、无依据编造文件结论属于必须修复的问题。
核心流程无法继续也应修复；英文错误较难理解、重试重复显示等体验问题单独记录严重程度。
若发现新问题，保存完整对话、当前附件名称、输入原文、实际回复、预期差异和截图，
不要为了“通过”临时改标准。修复后重测原失败项与相关链路。

这轮属于产品核验和回归，不是独立模型效果实验，也不替代 WHCNS 专业审核。
