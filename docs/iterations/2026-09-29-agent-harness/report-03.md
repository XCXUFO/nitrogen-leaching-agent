## 交付

- `/evaluation` 工作台：测试者执行用例、上传附件、多轮提问、手动备注、重置上下文、
  独立提交四层评分；开发者查看完整 Trace 和评分分布。
- 服务端访问密钥身份验证，测试者隔离、开发者权限检查；默认关闭评测 API。
  密钥摘要存于私有配置，原密钥仅保存在本机 600 权限文件，网页不持久化密钥。
- SQLite 新增不可覆盖的版本化 Case、Execution、有序 Event 和独立 Review。
  导入 32 条版本记录（26 个不同用例）；同版本标准变化时拒绝覆盖，必须创建新版本。
- 每次提问只能由后端绑定当前执行的 Run，浏览器不能指定他人的 Run/session/tester。
  上传事件也可单独评分；失败请求保留错误码和可用 Trace。
- 提交评分后冻结该次执行，重复提交被拒绝；复测新建执行。
  评分包含用例快照、有序 Run ID 和事件序号，重启后仍可读取。
- 服务重启或临时上下文失效时要求明确重置，历史证据保留，不复用未知旧指标。
- blocked 与待评分单列，各评分层排除 blocked/n.a.，partial 与 yes 分开，支持按用例版本查看。
  不将工程状态自动转成专业评分。
