## 如何填写

- 状态：待审核 / 已审核 / 缺材料 / 超出专长。
- 结论：通过 / 部分通过 / 不通过 / 无法判断。待审核项保持空白。
- 有问题时，记录回答中的具体原句、为什么有问题、应改成什么或还缺什么证据。
- 若能评分，专业正确性、完整性、证据支持、可理解性各填 0–2；
  0 表示关键错误/核心缺失，1 表示部分需修改，2 表示该项充分满足。
  不适用或无法判断留空并注明原因，不填 0 或 2 代替。
- 填写审核人和日期。涉及严重专业错误需明确标出，不用其他维度高分抵消。
