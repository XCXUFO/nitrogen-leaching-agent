# 工作台资料管理使用说明

更新日期：2026-10-17。适用于开发者、测试者和领域审核人。本文按当前工作区实现编写，涵盖文献、标签、案例与措施、星标问题及本轮风险修复。本文不表示这些功能已经部署到服务器；入口缺失时请负责人核对实际版本。

登录及评测流程见[工作台使用说明](evaluation-guide.md)、[测评者说明书](tester-user-manual.md)。以下模块均在侧栏“资料与证据”分组中，三个角色均可查看和维护共享内容。

## 1. 应该把内容放在哪里

| 入口 | 地址 | 用途 |
|---|---|---|
| 文献管理 | `/evaluation/literature` | 保存 PDF、题录、摘要、结论、来源和分类 |
| 标签管理 | `/evaluation/literature-tags` | 维护文献与案例共用的分类维度及多级标签 |
| 案例与措施 | `/evaluation/case-library` | 保存农业案例原文、表格、解释，并控制是否供 Agent 调用 |
| 星标问题 | `/evaluation/starred-questions` | 记录关注的专业问题，人工补录对应答案 |

“案例与措施”是农业业务材料；“评测管理 → 用例库”是测试步骤和通过标准，两者分别维护。文献保存或登记目前不会自动重建 RAG 检索索引；案例则在保存并开放后供相应案例 Skill 直接读取。星标问题是共享问答记录，不会自动向 Agent 提问或生成评测执行。

## 2. 文献管理

### 2.1 上传并登记一篇文献

1. 打开“文献管理 → 新增文献”，选择或拖入 PDF。单份上限默认 100 MB，以页面显示的环境配置为准。
2. 上传完成后，右侧显示原文并自动解析字段。上传本身只保存临时文件；点击“保存草稿”或“完成登记”后才出现在文献列表。
3. 对照 PDF 核查标题、作者署名顺序、发表形式、载体、年份、语言和 DOI。文件名仅是初始标题建议。
4. 展开“来源与补充说明”，填写来源、摘要、结论及必要的版本说明；选择分类标签。AI 操作见下节。
5. 材料尚不齐全时点“保存草稿”；字段齐全后点“完成登记”。已有登记记录编辑后点“保存修改”。
6. 返回详情确认保存的字段、结论、分类和 PDF；需要原件时点“下载”。

完成登记需要标题、发表形式、语言、来源，以及作者、发表载体、发表年份。作者、载体或年份无法确认时可明确勾选“未知”；语言选“其他”需补充说明；来源链接与出处说明至少填一项。启用且设为“登记必填”的分类维度也须选有效标签。DOI、摘要、结论不是必填项，但填写后须符合格式及长度要求。

### 2.2 AI 解析字段、结论与打标

| 操作 | 入口 | 返回后如何处理 |
|---|---|---|
| 上传后自动解析 | 上传 PDF 成功后触发 | 自动填入空白字段；已有内容保留，文件名生成的初始标题可替换为解析标题 |
| AI 解析字段 | PDF 原文预览上方 | 在“PDF 字段解析建议”中勾选字段，点“填入所选字段”；已有内容由你决定是否覆盖 |
| AI 解析结论 | 编辑页 → 来源与补充说明 → 结论 | 尝试提取结论章节原文；空白结论直接填入，已有结论需在建议面板选择覆盖 |
| AI 一键打标 | 编辑页 → 分类标签 | 根据 PDF 及当前标题、摘要、结论匹配现有启用标签；核查新增标签后可手动调整 |

这些操作都只修改当前表单，最后仍须点击“保存草稿”“完成登记”或“保存修改”。AI 输出需对照原文核实，尤其是作者、在线发表年份与卷期年份、结论的限定条件。结论支持换行，最多 20,000 字符；未识别到结论时可留空或手填。

建议先核对标题、摘要和结论，再执行打标。已有标签优先保留：单选维度不会追加冲突项，同一路径不同时追加祖先与后代；模型返回的未知、停用或冲突标签会被过滤。AI 不会替你新建分类维度或标签。提示“未找到可补充的匹配标签”不等于保存失败，可到标签管理检查分类是否齐全、启用。

字段解析在 AI 不可用时可返回本地 PDF 提取建议，并显示降级提示；打标失败则保留已有标签，允许重试或手选。当前未提供 OCR，扫描件缺少可选文字时须手工填写。解析只读取部分页面，未提取到某字段不代表原文没有。取消编辑或更换 PDF 后，旧 AI 请求的返回结果不会继续填入。

### 2.3 查找文献

1. 输入标题、作者、发表载体、DOI 或文献 ID，也可限定搜索字段。
2. 选择登记状态、使用状态和分类；发表形式、语言、年份、人员和日期在“更多筛选”中。
3. 点“查询”应用条件；点“重置”恢复默认筛选。默认使用状态为“正常”，找停用记录时改为“已停用”或“全部”。
4. 点击文献标题查看详情；列表可切换每页 20、50、100 条，翻页后回到列表顶部。日期显示及筛选按北京时间。

标签筛选遵循：选父级包含全部后代；同一维度多个分支为“或”，不同维度为“且”。例如选“广西”可匹配其下级地区；改选“南宁”会缩小同一路径的范围。地区名称仅为示例，实际选项取决于已维护的标签树。未打标文献也在全局列表中，选标签后可能被排除；历史分类可勾选“包含已停用标签”查询。

### 2.4 重复文件、版本和维护

| 情况 | 操作方式 |
|---|---|
| 相同 PDF 已存在 | 按提示“查看现有文献”；同名不是判断依据，系统检查内容指纹 |
| 不同 PDF 使用相同 DOI | 关联现有文献，填写“版本／差异说明”，勾选“确认作为不同版本继续登记”后保存 |
| 草稿需要换 PDF | 在草稿编辑页重新上传，再核对字段并保存 |
| 已登记论文有新版本 | 新增文献并关联原记录；已登记文献不能换原始 PDF 或退回草稿 |
| 暂时不使用 | 点“停用”并填写原因；之后可筛选已停用记录并“恢复” |
| 确需删除记录 | 填写删除原因并确认；这是逻辑删除，记录退出常规查询，页面没有删除后恢复入口 |
| 提示他人已修改 | 当前输入保留。先复制需要保留的修改，再点“加载最新版本重新编辑”，核对合并后保存 |

详情中的变更记录用于查看操作人、时间和修改内容。“已登记”表示完成登记校验，不代表文献已通过专业审核或已经加入问答索引。

## 3. 标签管理

1. 打开“标签管理”，新增分类维度，例如地区、作物。设置名称、说明、单选/多选、是否登记必填、启用状态和顺序。
2. 选中维度，在标签树新增一级标签；展开节点后点“新增下级”，逐级填名称并保存。最多五级，同一父节点下名称不能重复。
3. 用展开全部、收起全部或路径搜索定位标签。点节点“编辑”修改说明、父级、启用状态和同级顺序；不能形成循环、跨维度移动或超过五级。
4. 点“关联文献”或“关联案例”查看对应模块的标签筛选结果；节点的“直接关联”数量只统计直接关联，不等于包含后代的查询结果数。点“记录”查变更历史。
5. 历史分类不用时可停用；有子标签、文献或案例关联的标签不能直接删除，包含标签的维度也不能删除。

文献录入时，单选维度最多选一个标签，多选维度可选不同分支，同一路径不能同时保存祖先和后代。停用标签保留历史关联，不能新增关联；必填维度仍须有有效标签才能完成登记。调整共享分类会影响其他人的录入和筛选，应按团队约定维护。

筛选时，父标签勾选表示包含直接关联父标签及其全部后代的资料；仅选择子标签时，父标签显示半选，即使全部子标签都选中也不包含直接关联父标签的资料。点击半选父标签可纳入整个分类。

## 4. 案例与措施

### 4.1 录入原文与表格

1. 打开“案例与措施”，点“新增案例”。填写标题和“案例与措施原文”，二者必填。
2. 在正文保留背景、处理模式、条件、单位和例外。编辑器支持段落、小标题、编号、项目符号、表格及 Word 表格粘贴；可编辑单元格、增删行列、撤销和重做。
3. 粘贴后检查空白单元格、合并单元格、单位和行列对应。系统保留内容结构，不保证还原 Word 的字体、颜色或分页。
4. 按需填写“解释与说明”和“来源说明／链接”。新案例将背景与条件写入正文；旧案例已有的“原有补充信息”可继续编辑。
5. 点“保存”。新案例默认未开放；可先保存、核对，再开放给 Agent。

电脑端原文与解释并排，窄屏上下排列。列表支持标题关键词、开放状态筛选，按更新时间倒序显示，每页 20 条；详情保留案例 ID、创建人、最近修改人及时间。

### 4.2 生成并采用解释

1. 在编辑页点“AI 生成解释”，无需先保存表单。
2. 在“AI 解释初稿 · 尚未采用或保存”区域，对照原文检查事实、计量口径、条件和例外。空白不补值，合计不能当作单次用量，没有效果数据不能直接评价优劣。
3. 合适时点“采用初稿”，再人工编辑；已有解释被替换时页面会要求确认。不采用则点“放弃初稿”。
4. 点“保存”后解释才成为案例内容。采用后未保存就离开，不能视作已经入库。

生成失败可直接手填解释。生成后若修改了原文，须重新核对初稿。原文最多保存 50,000 字符；单次 AI 初稿的原文与原有补充信息合计最多 24,000 字符，富文本包含 HTML 标记。超过 AI 上限的材料仍可在保存上限内保存并手填解释。

### 4.3 开放与 Skill 效果验证

1. 核对保存内容后，在详情点“开放 Agent 使用”，或编辑时勾选“开放给 Agent 使用”并保存。
2. 在“Skill 效果验证”选择“案例与措施参考”或“案例与措施解释”。前者按场景找参考材料，后者解释案例或粘贴的专业文字。
3. 输入问题，点“验证效果”。详情页使用当前案例已保存、已开放的内容；列表页可参考已开放案例或直接解释粘贴文字。
4. 检查回答中的案例 ID、标题、实际来源与原文是否一致。发现事实冲突时交由人工核对，不以流畅程度判断正确。

只有已保存、已开放且未删除的案例可供案例查询使用，保存事务完成后直接生效。关闭或删除后，新请求及追问会重新检查开放状态；历史回答不会被改写。单次读取最多 30 条且材料 JSON 不超过 24,000 字符，超限会提示，可用详情页限定案例范围。

验证面板使用独立会话，输入和回答不会自动保存为案例，也不会自动生成评测 Execution 或评分；问答仍会产生运行记录。需要纳入正式评测时，另按评测流程创建用例和执行。解释内容不经人工核查就开放，可能把错误材料带入后续回答。

### 4.4 修改冲突与删除

保存、开放切换和删除均检查修订号。发生冲突时先在新窗口查看最新内容并复制待保留修改，再确认“加载最新版本”，手工合并后保存。删除为逻辑删除，并停止后续 Agent 调用；当前没有回收站界面。

本模块暂未提供 Word 文件自动导入、批量导入、独立措施对象、案例审核流或完整版本历史；Word 表格粘贴是正文编辑操作。

### 4.5 分类标签

案例与文献共用“标签管理”中的维度和标签。案例列表展示每条记录的标签；可按标签筛选，父标签包含后代，同维度为“或”、跨维度为“且”，可选择全部、已打标或未打标。筛选可叠加开放状态及关键词，关键词检索标题、正文、解释、补充信息和来源。

进入案例详情查看标签，点击“编辑”后在“分类标签（选填）”中按层级选择或移除，最后保存。新增案例也可直接选择。单选维度最多一个标签，同一路径不同时保存祖先和后代。文献的“登记必填”不强制用于案例；原有案例默认未打标。

案例总览每行可勾选，表头支持本页全选。选中后点击“批量操作”，在弹窗中选择“AI 一键打标”，系统按案例原文匹配已有启用标签，成功后替换并保存标签，无匹配保存为空；失败保留原值。弹窗展示逐条结果，“打标记录”可找回最近批次并重试失败项。处理中被人工修改的案例会跳过，须重新选择；切换筛选或页码会清空选择。后台中断条目超过 5 分钟后可恢复。

“批量操作”弹窗还支持“批量开放 Agent 使用”和“批量关闭 Agent 使用”。整批校验版本后保存，遇到已修改或已删除的案例整批不生效，刷新后重新选择；成功后自动更新列表，Agent 后续调用使用最新开放状态。

停用标签会显示“已停用”：已有案例可以保留或移除，不能给其他案例新增关联。标签改名和路径调整会同步显示；如层级调整或改单选会使现有案例标签冲突，系统要求先调整案例。标签管理显示文献与案例各自的直接关联数量，并提供“关联案例”入口。

## 5. 星标问题

1. 打开“星标问题”，点“新增问题”。
2. 填写专业问题；“对应答案（选填）”可留空，之后再补录。问题最多 20,000 字符，答案最多 100,000 字符。
3. 点“保存”，列表显示问题和对应答案；空答案显示“暂无答案”。
4. 收到答复或需要修正时，点该条“编辑”，修改后保存；取消则放弃本次表单修改。

这是三个角色共同维护的问题清单，并非个人私有收藏。页面当前按创建顺序显示，尚无搜索、删除、自动回答、聊天一键收藏或审核签核功能。填写答案不等于形成专家审核记录；需要独立审核时仍走审核队列。

加载失败可点“重试”；保存失败保留当前填写内容，检查网络和登录后重试。保存会校验编辑时的版本；他人已修改时会提示冲突并保留你的输入。先复制需要保留的修改，再点“载入最新版本”，核对合并后保存。当前没有历史版本恢复界面。

## 6. 常见问题与完成检查

| 现象 | 处理 |
|---|---|
| 看不到新菜单或 AI 按钮 | 核对实际部署版本；本文描述当前源码，不代表远程环境已经更新 |
| 刷新后表单内容丢失 | 登录保持不等于表单自动保存；先保存草稿或记录，再刷新 |
| AI 建议已填入但详情没变化 | 回编辑页核对并执行保存；解析、采用初稿和打标都不自动入库 |
| 文献找不到 | 检查登记/使用状态、标签和关键词；仅上传尚未保存的文件不在列表中 |
| 资料保存了，聊天没有引用 | 文献登记与检索索引分开；案例须已开放且问题走案例能力，星标问题不参与自动问答 |
| 401 或登录过期 | 用本人账号重新登录；网络验证失败时先点“重新验证登录” |

文献完成后核对 PDF、字段、来源、标签和结论；案例完成后核对表格、解释、来源及开放状态；星标问题完成后确认列表中的问题与答案。需要评价 AI 质量时保存实际问题、回答、时间和证据，专业结论由实际审核人给出。
