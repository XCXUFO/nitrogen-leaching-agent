# Skill 能力只读目录

日期：2026-10-17。实现范围：M08 的独立只读交付，依据 [V0.3 Skill 可视化 PRD](../2026-10-17-prd-review/revised-prd/08_Skill可视化与有限配置_PRD.md)。

工作台新增“Skill 能力”入口：`/evaluation/skills`。开发者、测试者及领域审核人登录后均可查看七项实际注册能力。列表支持按中文名称或注册标识搜索，详情展示业务用途、示例、输入要求、返回内容、支持边界和依赖；注册描述、真实输入输出 Schema 和当前版本信息默认折叠。

运行记录的“工具调用”明细可跳转当前能力说明，链接旁明确当前说明与历史运行事实的区别。未知独立 Skill 版本显示未采集，不能用当前运行配置补写历史版本。

## 数据及依赖状态

认证只读接口为 `GET /api/eval/skills` 与 `GET /api/eval/skills/{name}`，复用现有工作台认证和实际 `build_registry(...).describe()`。列表仅返回摘要，详情返回注册表真实 Schema；没有配置修改或执行工具的接口，未知能力返回 404。

- 文献服务未初始化时显示必要依赖不可用；模型客户端存在但未验证在线连通性时显示依赖待验证，不发送付费模型请求。
- 案例参考读取当前开放材料状态，区分未初始化、无开放案例、容量限制及读取异常。关闭记录后的再次读取即时更新状态；查询只读，不创建缺口或改动原材料。
- 粘贴文本解释不要求案例库；库内案例依赖标记为按输入使用，不能因该库不可用就把文本解释判为整体不可用。
- 附件检查分别显示 XLS、XLSX 解析依赖。缺少全部解析依赖时不显示完全可用；已缓存摘要仍按具体附件判断。WHCNS 分析的本地就绪指已校验摘要计算入口，不冒充通用表格或仿真能力。
- 状态按每次请求重读；不返回案例正文、内部路径、密钥或完整配置清单。异常依赖保留未知状态，不把原始错误透传页面。

说明模板按注册标识补充业务语言；新增注册能力没有模板时保留注册事实并显示说明／依赖未采集，不擅自宣称能力或就绪。

## 本次验收边界

| PRD 条目 | 本次交付 |
| --- | --- |
| V01—V03 | 七项真实注册能力可查，业务说明可读，技术信息折叠；真实输入输出从注册表导出 |
| V04 | 本轮全部配置只读，无保存、编辑或恢复默认的误导入口；服务端拒绝写入方法 |
| V05—V07 | 有限编辑、持久化配置、生效快照及恢复默认留到配置增量，本轮未实现 |

本次新增目录与展示，不改变规则路由、模型 Prompt、计算公式或聊天执行方式。文献、案例、星标等既有维护能力继续沿原入口使用。

## 验证记录

- 新增后端目录测试：15 项通过。覆盖角色访问、真实注册表与 Schema、未初始化依赖、模型未探测、案例材料开关及容量、格式解析依赖、未知版本与只读接口。

- TypeScript、变更前端文件 ESLint、独立生产构建通过。生产构建使用 `.next-skills`，没有覆盖现有服务产物；目录已纳入忽略规则及 Next 配置。
- 沙箱内 TestClient 等待超时、本地端口监听受限，经授权在沙箱外完成测试。浏览器验证使用模拟接口；后端接口用独立 TestClient 与内存数据库验证，没有调用真实模型或改动业务库。

各项结果及实现文件指纹见 [verification.json](verification.json)。本次未部署到现有运行服务。
