## 实际回放示例

光合作用可以理解为绿色植物（也包括藻类等）利用光能，把二氧化碳和水合成有机物并释放氧气的过程[1][2]。这里的“有机物”可以通俗地看成植物为自己制造的“食物”，而光能则被转成储存在有机物中的化学能[1]。从更广的意义看，它把太阳能转成生物能，把无机物变为有机物，并维持地球的碳氧平衡[3]。

这个过程大致分两步。第一步是“光反应”，需要光，在叶绿体的类囊体膜上进行：光合色素吸收光能，引起电子传递，水分解并释放氧气，同时形成ATP和NADPH＋H＋[4]。这两种物质被称为“同化力”，可以理解为推动下一步的“能量和还原力货币”[4]。第二步是“暗反应”，不需要直接光照，在叶绿体基质中进行：利用同化力固定二氧化碳，把它转成有机碳[4]。所以，光反应的实质是产生同化力去推动暗反应，暗反应的实质是利用同化力把无机碳转化为有机碳[4]。

用一个日常场景来理解：晴天里，一片叶子吸收阳光和空气中的二氧化碳，根部吸收的水分被运到叶片；叶绿体先“捕获”光能，再把这些能量用于把二氧化碳“组装”成糖类等有机物，同时把氧气释放到空气中。人和其他生物呼吸所需的氧气、食物链中的有机物，很多都间接来自这一过程（这一延伸为一般知识补充）。

需要澄清一个常见误解：光合作用并不是“植物吸二氧化碳、吐氧气”这么简单的一句话，它内部包含光能吸收与转换、电子传递、光合磷酸化和碳同化等步骤[2]；不同植物固定二氧化碳的途径也有差异，例如C3途径、C4途径和CAM途径[4]。对初学者来说，先抓住“光能→化学能、无机碳→有机碳、释放氧气”这条主线即可。
