# 线上效果：会话维度看板

看板以会话为观察与后续 harness 评估单位，每轮主运行、重跑、Skill 与步骤保留为执行明细。多轮上下文正确性尚未评分，运行正常不代表任务完成或专业回答合格。

## 数据与统计口径

- 数据来自运行记录使用的 `agent_runs`，并关联 `chat_submissions`，纳入已受理但缺 Trace 的运行；无 submission 的历史与同步评测 Trace 也纳入，来源沿用持久化标记，未标明的历史记为 legacy。
- 按所有者、持久化会话标识、可信来源分组。不同来源分开统计，同一会话的所有首次主运行构成提问轮次；只用显式主运行关联识别重跑，不按问题文本猜测。
- 时间范围按会话第一轮受理时间选择。跨日、跨版本和跨模式的后续轮次仍留在完整会话中；该日期 cohort 的累计轮次与状态会随后续追问更新。
- 模式、配置版本、实际 Skill、任务类型须在同一主运行中匹配。命中后选中整个会话，汇总会话内全部主运行及其调用，不截断前后文。
- 任一主运行失败、取消或中断，记为含异常轮次；其余优先记为存在执行中轮次，再记为状态待确认，全部 succeeded 才记为截至当前全轮正常。状态可用于筛选完整会话，不表达用户已经结束对话。
- 会话数按分组去重；多轮会话占比为至少两轮的会话数 / 会话数；平均轮数为主运行数 / 会话数。无样本时比率和均值为空，不显示为 0% 成功或失败。
- 任务类型和 Skill 的涉及会话数均在会话内去重，分组允许交叉；调用数、失败次数、平均调用耗时和步骤成功率仍保留各自执行口径。
- 重跑独立统计涉及会话数、运行次数及恢复结果，不增加提问轮数或清除原主运行异常。轮内步骤重试仍按原步骤与 attempt 口径计算。
- 开发者额外收到最近创建的 20 个命中会话，可沿已有运行记录接口查看连续问答、状态与上下文；审核者只收到汇总，不能通过该接口获取会话主题。

API `/api/eval/online-metrics` 返回 `metric_version=session-primary-v1`、`unit=session`。新增 `sessions`、`session_states`、`multi_turn`、`mean_turns`、`turn_distribution`、`recent_sessions`。`questions`、`states` 保留为所选完整会话中的主运行统计；`by_task` 改为涉及会话数，`by_skill` 增加 `sessions`，`daily` 按会话创建日统计。`status` 取 normal / abnormal / running / unknown。

验证覆盖完整多轮与跨日 cohort、同轮条件匹配、任务与 Skill 会话去重、来源及所有者隔离、缺 Trace、历史 Trace、重跑与持久化、接口权限、浏览器筛选与会话下钻、移动端布局。
