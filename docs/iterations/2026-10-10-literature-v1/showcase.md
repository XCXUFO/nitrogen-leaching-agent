# Showcase 文献流程示例

## 公开入口

- `/showcase`：新增「体验文献管理」入口卡片。
- `/showcase/literature`：示例文献概览、搜索、状态与层级标签筛选。
- `/showcase/literature/new`：载入示例 PDF → 保存草稿 → 补充信息 → 选择标签 → 完成登记。
- `/showcase/literature/SAMPLE-001`：预置未打标草稿，可继续整理。
- `/showcase/literature-tags`：维度、完整标签路径、关联数量与新增示例标签。

桌面侧栏和移动导航均包含「文献管理」「标签管理」。原有评测案例入口保留。

## 演示行为

使用 3 条合成文献、3 个示例维度（V1.1 增加地区三级示例）；示例数量与正式库数量分别展示。未打标文献默认全局可见。正常列表不展示停用记录，点击数量卡片可切换筛选；父标签筛选包含下级关联。

访客无需登录，可以保存示例草稿、补充信息、打标、完成示例登记、编辑、停用及恢复。编辑已登记示例仍校验登记字段；编辑停用文献不会自动恢复。记录只在当前浏览器页面体验中生效，跨模块导航保留，刷新或「重置示例」恢复初始状态。新增示例文献的临时详情地址在刷新后提示记录已重置。

示例标签支持同级唯一名称和最多五级层次，选择祖先或后代标签时自动移除冲突关联。示例维度均非必填，允许文献保持未打标状态。正式维度配置仍在管理后台维护。

预览与下载统一使用 `frontend/public/showcase-assets/literature-workflow-sample.pdf`：一页自制英文流程说明文件，明确标注为合成示例，不是真实论文。界面同样标明示例身份。

## 数据边界

- 不查询或写入 `/api/literature`、`/api/eval`。
- 不公开正式库原始 PDF、内部备注、人员或迁移映射。
- 不申请管理密钥，不保存登录信息。
- 文献示例直接使用前端独立数据，在公开案例接口不可用时仍可体验。
- 完成登记仅表示信息完整，不显示质量审核结论。
