# V1.1 筛选与批量操作收口（2026-10-16）

本轮核对后保留已有自动／指定 Skill、实际路由展示、双 Skill 串联、多案例追问、标题替换内部 ID、无匹配需求记录，并对相关案例与 Agent 测试进行回归。案例缺口入口仍是人工维护清单，不自动向外发通知。

案例总览改为横向紧凑筛选栏：关键词、开放状态、打标状态、标签维度依次排列，窄屏自动换行。关键词按字面匹配标题、正文、解释、补充信息和来源。打标状态支持全部／已打标／未打标，与标签、关键词、开放状态组合使用；切换筛选清空勾选。共用标签组件不再展示“同维度或、跨维度且”说明，匹配语义保持不变。

总览仅保留“批量操作”和“打标记录”入口。选中至少一条后可打开批量弹窗，选择 AI 一键打标、批量开放 Agent 使用、批量关闭 Agent 使用。成功后更新列表并清空选择；失败保留选择和具体错误。AI 任务仍有逐条回执及失败重试。

新增认证接口 PATCH /api/case-library/batch-availability，接收 items（case_id、expected_revision）及 enabled，限制 1～100 条且不可重复。所有更新在单个事务中执行 SQL revision 校验，任何记录冲突或已删除均整批回滚，不出现部分开放／关闭。记录修改人与时间并递增版本，Agent 下次读取立即按最新状态过滤。运行中的 AI 打标若与该操作冲突，遵循已有版本冲突跳过机制。

GET /api/case-library 新增 tag_status=all|tagged|untagged，保留旧 untagged 参数兼容调用。
