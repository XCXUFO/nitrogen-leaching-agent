# V1.2 文献操作补丁

- 结论与其他字段统一通过“AI 解析字段”生成建议，核对后填入；移除结论专用按钮。
- 单个导入、批量导入并排展示。批量导入在弹窗内先上传校验，过滤空文件、格式/大小不符、已有文献和批内内容重复文件，再独立选择字段解析与打标，提交有效文件并显示录入结果。两项 AI 均可不选；新文献仍按现有规则保存草稿。
- 已有文献批量 AI 使用独立弹窗，仅查询当前批次。全部成功显示流程完成及明细；异常保留原因并支持逐篇重试、主动关闭。关闭流程不会取消后台任务。
- 分类筛选增加“未打标（全局）”，只匹配完全没有任何标签的文献（带停用标签也不算未打标）；与具体标签互斥，可叠加其他列表筛选条件。
- 筛选父级选中时下级同步勾选，下级全选时父级同步勾选，取消任何子级后父级取消勾选并保留其余分支。移除“完成选择”及父级包含提示，使用关闭图标、点击外部或 Escape 收起。

接口：新增 `GET /api/literature/imports/{id}`（仅任务所属用户），重试接口支持可选 `paper_ids`，列表接口支持 `untagged=true`。无需数据库迁移。

后续修正：勾选或取消“未打标（全局）”立即查询并返回第一页，不再仅修改待查询条件。标签选项扩大为整行点击区域，修复点击文字时失焦提前关闭弹层的问题；展开箭头仍独立操作。新增仅带“作物：玉米”标签的排除回归，以及立即筛选、刷新保留条件和文字/空白区域点击测试。相关接口 11 项、针对性交互 2 项测试通过。

验证：后端相关测试 34 项通过；浏览器相关用例累计 12 项通过（使用已安装 Chromium channel），1 项依赖独立 8107 fixture 的历史集成用例按原条件跳过。TypeScript、修改组件 ESLint 和 diff 空白检查通过。

实际运行验收：启动当前源码的后端 8000 与前端 3000，使用既有测试账号只读查询现有库。`usage=all` 时共 112 篇；`untagged=true` 返回 78 篇，逐条检查 78 篇的 `tag_ids` 均为空。后端直连与前端代理结果一致，未筛选列表中存在 34 篇有标签文献。此次验证使用实际接口，不使用模拟返回值；账号凭据未输出。

真实浏览器验收通过：访问 `http://localhost:3000/evaluation/literature`，登录后勾选“未打标（全局）”，页面显示 78 条结果，首屏 20 篇均无标签。服务已保持运行。浏览器使用 localhost（与 Next 开发资源来源一致）。
