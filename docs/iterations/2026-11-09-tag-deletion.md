# 共享标签删除补丁

原行为：标签关联文献或案例时返回 `409 tag_in_use`，只能逐条解除关联或停用标签。

新行为：删除标签时自动解除全部文献和案例关联，包含停用及逻辑删除记录；保留资料正文、原文件、其他标签及可用状态。返回实际解除关联的文献和案例数量。若删除后缺失必填分类，文献详情沿用现有“必填维度待补充”提示，不改动登记状态。

文献关联、案例关联、标签及操作记录通过 SQLite 附加数据库在同一事务提交，失败全部回滚。受影响记录增加版本号，过期编辑请求无法覆盖修改。文献检索元数据变更沿用原有索引失效和自动同步机制。新增按标签查询文献关联的索引。

界面删除确认说明解除关联、保留内容和当前关联数量；成功后显示实际处理数量，清理当前编辑状态及当前浏览器保存的该标签筛选。

范围：有子标签的父标签仍需先移动或删除子标签，避免隐式删除整棵分类树；维度删除规则不变。无需提供新配置。补丁未部署到线上，未操作实际业务记录。

验证：65 项后端回归通过，覆盖 1101 篇文献与 30 条案例的批量解绑、仅文献库启用、其他标签保留、停用及已删除资料、版本冲突、权限、父子层级保护、事务回滚、标签推荐及检索同步。浏览器覆盖确认、取消、成功后的实际计数和编辑状态、错误保留、保存筛选清理；TypeScript、ESLint 和差异格式检查通过。
