# 游客展览工作台同步

将 `/showcase` 从早期文献登记展示更新为当前工作台主要流程的免登录体验。正式资料和历史证据快照未导出、修改或补造。

## 内容

- 总览标明同步日期，展示文献批处理、案例与措施、星标问题和共享标签入口；快照 API 失败时，体验入口仍可使用。
- 导航复用正式工作台模块名称与分组，桌面可收起，手机保留横向导航。
- 文献列表支持选择及筛选后清空选择、独立字段/打标开关、预置混合导入批次、失败重试和审核入口。重试沿用提交时开关，成功项不重复处理。
- 单篇文献可选择性采用预置字段、摘要、结论及标签建议，保存后详情可核对；原登记状态与使用状态保留。
- 案例与措施支持新增编辑、正式富文本/表格编辑器、解释初稿采用与放弃、共享标签、批量打标和开放控制。
- 固定问题演示案例参考、解释、比较与追问；每次重新检查开放状态，关闭后的案例不进入新一轮演示来源。
- 星标问题支持问题及人工答案新增、编辑；说明真实共享保存和版本冲突保护由正式工作台提供。
- 标签管理展示文献和案例关联数，支持跳转层级筛选。

## 数据和行为边界

新增材料为代码内合成常量。AI 建议、解释与回答均明确标注为预置演示，不调用模型，不代表质量审核结果。批量导入是固定流程，不接收真实 PDF；文献预览沿用自制的流程说明 PDF。

所有体验共用 showcase 布局中的 React 内存状态，站内切换保留，刷新或重置后恢复初始值。处理回执同样不持久化。真实后台任务持久化、并发修改保护与需求聚合以说明呈现，未伪装为已在游客体验中执行。

展示流程不访问正式文献、案例和评测 API。现有公开运行仍来自 `/api/demo/catalog`，来源、指纹、合成评分及待专业审核标识继续保留。文献登记不自动建索引，星标不自动进入检索或评测。
