# 聊天页 P00 会话附件修改与验证

依据：用户本轮反馈及 Windows 桌面的《【导出】聊天页体验：按顺序测试并在表中填写.pdf》（10 页）。已查看第 2、7、9 页及嵌入截图，补入截图原句“有其他信息不”。本记录为 Codex 新会话自动测试，未使用、修改任何他人评分。

## 修改后的行为

- 上传文件属于会话。主聊天请求携带 `file_ids`；后端逐份检查、按问题中的文件名和字段选择相关文件，支持一问分别计算多张表的整表极值。
- 发送后“收起文件”只隐藏卡片，文件继续可引用；可展开。发送前仍可移除。新对话清空历史、草稿和附件。
- 追问优先沿用最近核验的文件与字段，必要时从用户历史恢复字段，再重新计算；不把历史答案中的数字当作新证据。缺少或无法确定对象时只请求补充信息，不附文献。
- “有其他信息不”在存在会话文件时，列出文件和可查询字段，提示下一步可问的统计项；没有上下文时请求补充细节。
- 上传前按 SHA-256 判断重复，跨批次、改名副本和已收起文件也参与查重；重复文件自动跳过并提示。同名不同内容保留且显示摘要。
- 正文仅保留实际使用的引用，按首次出现从 1 编号；同一论文合并摘录，文献列表与正文对应。引用跳转仍按回答轮次隔离。
- 复制按钮成功后显示“已复制”，1 秒恢复“复制回答”。移除容量/30 分钟的常驻小字，超限或失效时再提示。

兼容说明：旧评测/嵌入客户端仍可发送单个 `file_id`，保持原合同；主聊天使用新的会话 `file_ids` 合同。新文件模式已添加独立回归。
