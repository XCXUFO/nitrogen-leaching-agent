# 会话用例驱动的轻量评测

## 日常入口

- `/evaluation/runs`：查看完整运行会话，标记问题，点击「加入用例组」保存整段会话。
- `/evaluation/issues`：统一处理运行标记、前台反馈和历史执行问题。归类、指派处理人，关联会话用例；在问题内查看各版本回答。
- 「会话用例组 → 用例组管理」`/evaluation/case-groups`：维护固定用例组、会话用例与预期标准；通过「验证此组」进入版本管理，自动选中当前组。
- 用例组内直接显示各轮原始提问；点击用例进入 `/evaluation/case-groups/{group_id}/cases/{case_id}` 独立详情页，查看原回答、预期和版本对比，并可返回所属组。旧的 `?case=…` 链接自动跳转；未指定组的用例链接进入 `/evaluation/case-groups/cases/{case_id}`。
- 「会话用例组 → 版本管理」`/evaluation/case-groups/versions`：选择一个或多个组，填写版本名称后重跑，查看验证记录、逐会话验收与多版本回答；支持单段完整会话重跑，开发者可确认版本、恢复已确认配置。旧的 `case-groups?batch=…` 链接会转入版本管理，保留批次和用例。

流程：发现问题 → 保存会话、填写预期并归组 → 修改 → 重跑 → 人工验收 → 开发者确认版本。

会话用例保存当时所有已记录轮次，包括请求选项、起点历史、原回答与版本、原附件指纹。原会话新增轮次不会改动已保存用例。相同快照可属于多个组，联合重跑按用例去重。更新预期只影响后续验证，已运行批次的输入和标准保持不变。

每次重跑使用独立会话，后续轮次承接本次实际生成的回答。按原始 SHA-256 从持久附件档案恢复文件，结束后释放临时能力；原件缺失或指纹不符时明确受阻。参考答案和预期不会发送给 Agent。支持每个会话 1–40 轮、单次 1–100 段会话、最多联合选择 10 个组。

运行成功与验收通过分开记录。逐个会话填写核对依据、选择符合预期或仍有问题；没有冻结的预期、缺失轮次或运行异常都不能确认通过。取消和服务重启会保留中断状态，不会自动再次调用模型。提交编号用于网络重试去重。

## 权限

现有账号角色保持兼容：`developer` 为开发者、`reviewer` 为专家、`tester` 为普通只读账号。

| 操作 | 开发者 | 专家 | 普通账号 |
| --- | --- | --- | --- |
| 查看运行、会话用例组、问题及版本回答 | 是 | 是 | 是 |
| 保存会话、维护预期、归组、重跑、取消、验收、日常 Prompt 对比评测 | 是 | 是 | 否 |
| 归类、指派和处理问题 | 是 | 是 | 否 |
| 修改 Prompt、表达配置、文献和案例资料 | 是 | 否 | 否 |
| 确认版本、恢复已确认的配置 | 是 | 否 | 否 |
| 前台提问、个人会话附件、反馈自己的回答问题 | 是 | 是 | 是 |

后端 `authorize_workbench` 统一约束新旧工作台写接口；确认与恢复接口另有开发者检查。普通账号前台反馈不受后台只读限制，服务端从登录身份或签名访客身份验证反馈回答的归属，不信任提交方提供的操作者或会话编号。

## 版本确认与回退的实际范围

开发者只能确认所有会话均运行完整且经人工验收通过的批次。确认时再次校验当前服务与 Prompt/表达快照，配置变化后不能沿用旧验收。保留确认者、说明、当时的人工作业及配置快照。

「恢复此已确认版本的配置」实际恢复全局 Prompt、三个任务 Prompt 和表达偏好，保存恢复前后快照。仅允许同一服务构建，且不能打断正在运行的会话评测。

**当前未接入服务代码部署回滚，也不回退文献、案例或索引。** 页面明确显示这一范围；版本确认记录不表示已完成代码部署。服务代码发生变化时，配置恢复接口会要求先经原部署流程处理代码版本。
