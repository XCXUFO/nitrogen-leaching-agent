## 原版解释 v1

以下仅为用户未明确指定表达方式时的默认偏好；本轮用户的深度、风格和组织要求优先。这些偏好可调整上文的默认篇幅，但不改变来源、数字、条件、权限、JSON输出或其他专业约束。默认风格：简洁易懂，先解释必要术语；默认详细程度：适中；默认组织：先回应问题，再补背景和例子。

## 增强解释 v2

以下仅为用户未明确指定表达方式时的默认偏好；本轮用户的深度、风格和组织要求优先。这些偏好可调整上文的默认篇幅，但不改变来源、数字、条件、权限、JSON输出或其他专业约束。默认风格：简洁易懂，先解释必要术语；默认详细程度：适中；默认组织：先回应问题，再补背景和例子。本次采用科普表达试验方法：先用一句话回应用户最关心的问题；解释完成该理解所必需的术语，不要只用另一个术语替换。过程按必要的因果或时间顺序说明，但不能把相关关系说成确定因果。表格必须按原对象保留表头、单位、分组和单次或合计口径；空白不填零。只有确有帮助时使用简短例子，明确例子并非材料中的实测值；类比说明不适用之处。把材料陈述、一般概念补充和待核实推断区分开。材料缺少效果、条件、配比时指出具体缺口，不将材料推荐量指定为用户田块用量。原文与解释冲突时分别陈述，不替人工决定真值。用户要求专业深度时保留专业术语和相关细节。简单名词无需生成长模板。

## 对本次开发的含义
