# 评审决策与验收安排

版本：V0.3｜日期：2026-10-17

V0.3 补齐开发前审查 R01—R05；跨模块规则统一引用[运行、检索与审查契约](14_跨模块运行与审查契约.md)。本次是文档修订，不表示应用功能已实现或验收。

## 1. 本轮先确认范围

先决定本轮要推进哪些增量模块，再确定各模块策略。历史功能不再逐条重新审批；若本轮联调发现旧缺陷，关联原需求及问题记录。

本清单是评审准备，不要求用户先全部回答才可使用 PRD。

## 2. 尚未决定的策略

| 事项 | 现有初稿建议 | 需要决定的原因 |
| --- | --- | --- |
| 星标匹配阈值和候选数 | 用真实同义、近似反例校准 | 防止高相似但不适用的答案被采用 |
| 文献同步触发 | 可先手动闭环，之后评估自动入队 | 当前登记和索引独立，需适配现有任务 |
| 文献入索引资格 | 优先正常且满足登记要求的记录 | 历史索引未必有完整登记映射 |
| 更新时是否继续提供旧片段 | 初稿倾向避免过期内容进入新证据 | 一致性和可用性之间的具体业务选择 |
| 案例扩容实现时机与技术 | 先验证条数／字符超限容量拒绝及不同排序位置召回，再定实现 | 不预设必须更换向量基础设施 |
| 标签同义表达维护 | 先小规模配置，页面后续决定 | 不为映射先新建管理平台 |

| 回答文字流 | 与执行事件流分开评估 | 模型客户端当前能力边界不同 |

| 抽样比例、保留期及后续主运行政策变更 | 首次已受理运行是默认主运行；随机与异常分开，具体比例／时长按环境确定 | 保留窗口须声明；政策变更另版本化，不回写默认主运行关系 |

### 2.1 V0.3 已收敛的规则

R01—R05 按共享契约实施：案例全量候选与取材预算分离；幂等提交先受理再执行；断线只恢复不重做；正式 Run 可直接审查，相关性和充分性独立；语义条件不等同标签成员；执行与业务双字段、同层级统计；默认主运行为首次已受理运行。这些不再作为未定义行为，也不代表当前应用已具备能力。

## 3. 新增验收与回归的区分

| 类型 | 示例 | 如何处理 |
| --- | --- | --- |
| 新增链路验收 | 星标部分命中后继续检索 | 本轮必须证明新行为正确 |
| 调整接口验收 | 统一 Query 真正传入现有检索 | 核对字段、行为和可观察记录 |
| 既有回归 | 案例表格、解释草稿、文件极值 | 按本轮影响范围复用已有用例 |
| 历史未完项 | 旧版本批量弹窗或父子选择问题 | 回原迭代，不自动扩大本轮 |
| 研究试验 | 外部解释方法同题对照 | 记录结果再决定是否启用 |

回归保护是为了不破坏已有能力，不代表为历史全部功能重新开发或重新建立一套测试。

## 4. 建议优先运行的联合场景

| 编号 | 场景 | 观察点 |
| --- | --- | --- |
| E01 | 已有星标问答同义提问 | 问题适用、完整覆盖时正确复用 |
| E02 | 命中空答案和部分答案 | 后续能力仍实际执行，已覆盖内容保留 |
| E03 | 两案例追问、更正作物和切换话题 | 新统一理解不破坏已有上下文 |
| E04 | 资料有内容但标签不全 | 正文明确满足用户硬条件时可核对召回，不因缺标签提前排除 |
| E05 | 已登记论文未进入索引 | 后台状态准确，完成同步后能查到 |
| E06 | 31 条去重后独立开放案例及不足 30 条但字符超限 | 现状为容量报错；新增候选搜索不被全库预算阻断，相关案例在不同排序位置均可达 |
| E07 | 资料关闭、停用、删除 | 原管理动作在新链路中继续生效 |
| E08 | 计算成功、文献分支失败 | 保留已有部分成功行为，进度和后台一致 |
| E09 | 修改允许的解释字段 | 新运行生效，历史与运行中配置不被改变 |
| E10 | 事件断线、乱序、重复 | 显示可恢复，不重复执行任务 |
| E11 | 解释候选与基线同题 | 专业准确、易懂性分别评审 |
| E12 | 未审查、部分正确、指定模式和重跑 | 指标分母与排除项可核对 |
| E13 | 受理成功但首个回执丢失、网络重发 | 用同一 request_id 找回同一 run_id；异输入同标识返回冲突，工具只调度一次 |
| E14 | 最终答案已形成但客户端未收到 | 恢复完整答案、引用及文件／案例证据；结果快照与终态一并保存 |
| E15 | 结果保存失败或执行中服务重启 | 不通过重跑工具补保存，已知事实保留；不明动作标中断／未知，不自动重放 |
| E16 | 同轮主动重跑、编辑问题及继续追问 | 重跑新建提交与运行并关联原轮次；编辑和追问新建轮次，运行中不并发重跑同轮 |
| E17 | 跨访客／跨账号找回、订阅或取消 | 服务端归属校验拒绝，不通过公众恢复暴露开发者 Trace 或人工审查明细 |
| E18 | 事件缺失但完整结果仍在、恢复窗口过期 | 前者返回完整结果并说明过程不全；后者返回过期，不把旧提交当新任务 |
| E19 | 无标签正文满足、标签正文冲突及条件未知 | 满足可采用；冲突须核对且未解决不称匹配；未知不猜测满足，实际阶段与依据可查 |
| E20 | 明确要求只查带某标签的记录 | 按显式标签成员筛选，与一般语义条件分开记录 |
| E21 | 单条关键案例超预算、显式小范围案例 | 不截断表格或串换对象，小范围继续可用；预算不足不要求关闭其他真实资料 |
| E22 | 正式 Run 审查、重复提交及并发修订 | 不伪建评测 execution，具备审查权限者可保存；去重及 expected_revision 生效，历史保留 |
| E23 | 旧 n.a.、旧证据总评、AI 辅助及冲突 | 不推断新增人工维度；草稿、AI 辅助、待复核不进有效覆盖分子 |
| E24 | 共享契约 S01—S06 | 工具步骤成功率 2/3、尝试失败率 2/4；无结果、跳过、取消、澄清及父子层级分别计 |
| E25 | 相关但不充分、不同维度无法判断 | 相关性与充分性独立保存及计算，无法判断仅排除对应维度；零分母不显示百分比 |
| E26 | 失败主运行后成功重跑、历史补审 | 主运行不被替换；网络重发不增轮次；当前审查修订更新统计且不重复计数 |

## 5. 实际交接建议

产品与研发对照能力差异表，仅为本轮模块补充实际接口、字段和版本。专业同事提供少量有代表性的问题及原文，优先复用已有评测资产。文档中尚未确定的参数保留待确认，不靠假设填满。

不把取得全部 25 条星标原文、迁移全部历史论文或接入所有外部来源，设为所有增量模块的共同前置条件；各模块按实际依赖推进。
