# M03｜文献管理与 RAG 衔接 PRD（增量修订）

版本：V0.3｜日期：2026-10-17｜状态：审查修订，待开发验收

V0.3 补齐开发前审查 R01—R05；跨模块规则统一引用[运行、检索与审查契约](14_跨模块运行与审查契约.md)。本次是文档修订，不表示应用功能已实现或验收。

## 1. 已有基础与剔除的重复需求

B2 文献 V1.0—V1.2.1 已定义上传、登记、预览、题录、重复检查、多级标签、单篇和批量 AI 解析／打标、批量导入、当前批次明细及失败重试等功能。B4 能力盘点确认相应管理、批处理和 RAG 实现存在。

上一版重写的新增按钮、批量弹窗、默认勾选、表单布局、统一解析按钮、保存草稿与字段要求全部移回历史需求，不作为本轮新建任务。历史补丁若仍有未完成项，回原迭代跟踪，不自动塞进本轮。

本轮重点是已存在的文献管理与已存在的 RAG 之间的衔接。B4 明确两者目前独立，登记不会自动重建索引。

## 2. 本轮目标与范围

1. 让后台清楚显示文献是否已能被聊天检索，以及未就绪原因。
2. 为新保存、变更和历史记录建立可追踪的索引同步关系。
3. 查询使用统一 Query、关键词和标签条件，不要求资料先完整打标。
4. 保证停用、删除与更新不会让新请求采用不应使用的片段。

不重做文件上传、RAG 分块向量化、批量 AI 任务和文献版本管理。OCR、外部自动抓取、质量审核和付费全文获取不在本轮。

## 3. 页面增量

在现有文献列表增加“检索状态”及必要筛选，在详情增加同步摘要：当前内容标识、索引版本或时间、最近任务结果和失败原因。

提供失败重试和按需同步入口，优先复用既有任务机制。状态字段不替代草稿／已登记、正常／已停用；既有 AI 字段解析成功也不代表全文已入索引。

| 建议状态 | 说明 |
| --- | --- |
| 未准备 | 尚不满足入索引条件，显示原因 |
| 待处理／处理中 | 已入队或正在正文与索引处理 |
| 已就绪 | 当前内容与可用索引一致 |
| 更新待同步 | 内容或影响检索的元数据已改变 |
| 失败 | 指定环节失败，可查看原因重试 |
| 不参与检索 | 停用、删除或明确不具备资格 |

状态命名和是否合并待处理／处理中属于初稿建议，应适配现有系统，不要求新增一套独立后台。

## 4. 同步业务规则

有效保存 → 按资格判断 → 进入现有适用处理机制 → 关联原件、正文片段与索引 → 校验完成 → 标为就绪。

- 自动入队是本稿建议，待评审；可先用手动同步验证闭环，再扩展自动触发。
- 入索引资格建议先限定正常、未删除且满足登记要求的记录；历史无登记映射的索引需单独迁移核对。
- 首先建立文献、文件、正文片段和索引关联，避免重复构建已有索引。
- 标题、来源、标签等变更同步受影响元数据；文件或正文变化才进行相应内容更新。
- 重试同一内容版本应幂等；旧任务不能覆盖较新版本状态。
- 扫描件没有可读正文时不标记全文就绪，仍可按原规则保存或预览。
- 更新待同步期间是否保留旧索引是待确认政策；初稿建议不向新请求提供过期片段，必要时使用其他资料。

## 5. 检索接口调整

复用现有文本、向量、重排及数值检索能力，接收 M01 的 Query、关键词和条件以及 M05 的标签映射。先核对当前可用路径，只补缺失接口和过滤机制，不默认替换检索技术栈。

明确约束用于语义适用性核对，不直接等同于“资料必须有某标签”。先执行停用／删除和访问资格约束，再合并标签、正文和语义候选；缺少标签不在正文召回前排除。按共享契约第 4 节区分满足、不满足和未知；推断标签只辅助排序。强条件无结果时不得静默撤销条件。

正文明确满足而无标签的资料可核对后采用；标签与正文冲突时记录冲突和核对依据，未解决前不称严格匹配；正文与标签均无法确认时不作为满足硬条件的证据。如用户明确要求“只查带某标签的记录”，才按该显式标签条件筛选。

证据返回文献与原件标识、实际采用片段、可得定位及版本。页码不可得时标明实际定位方式，不编造页码。元数据或摘要命中不能被描述为已阅读全文。

## 6. 失效与历史兼容

停用、删除影响新请求的可用资格；即使物理索引尚未清理，返回证据前也须排除。沿用原管理动作，不新增停用流程。

历史回答保留当时证据关联；访问旧原件沿用现有权限。历史索引缺少映射时显示未知来源关联，不把当前文献版本补写成当时事实。

上传、AI 解析、保存、正文提取和索引失败分别定位。本轮不修改 AI 自动填入或覆盖策略；原流程的问题仅作为兼容验证或旧迭代缺陷。

## 7. 本轮增量验收

| 编号 | 验收内容 |
| --- | --- |
| L01 | 已保存但未索引与当前已就绪可区分，状态来源可查 |
| L02 | 新记录、更新记录和历史映射可完成同步；失败可重试且幂等 |
| L03 | 旧同步任务不会把较新内容误标为已就绪 |
| L04 | 统一 Query 和标签条件进入真实检索，未打标资料仍有可验证召回路径 |
| L05 | 停用、删除记录不进入新证据，过期索引处理符合最终政策 |
| L06 | 引用定位到实际原件及版本，不把摘要命中当全文 |
| L07 | 既有导入、解析、打标和批处理回归通过，无重复记录或被动覆盖 |
| L08 | 无标签但正文明确满足硬条件的文献可进入候选并核对采用，实际过滤阶段可查 |
| L09 | 标签与正文冲突时保留核对证据，未解决前不冒充严格匹配 |
| L10 | 正文与标签均无法确认时标未知，不猜测满足；显式标签筛选与语义条件有区别 |

## 8. 依赖与待确认

需确认现有索引到文献记录的映射、资格、触发方式和更新期间政策。批量上传上限、表单必填及已登记文件替换继续执行历史最新规则，本稿不重定义。
