# M05｜语义关键词到共享标签映射 PRD（增量修订）

版本：V0.3｜日期：2026-10-17｜状态：审查修订，待开发验收

V0.3 补齐开发前审查 R01—R05；跨模块规则统一引用[运行、检索与审查契约](14_跨模块运行与审查契约.md)。本次是文档修订，不表示应用功能已实现或验收。

## 1. 已有基础与本轮边界

B2 已定义多维度多级标签、父子联动、同维度或／跨维度且、全局未打标和紧凑筛选；B1 将案例打标与文献能力拉齐；B4 确认共享标签、层级查询及 AI 建议已有实现。

本轮不重建标签体系，不把父级全选、半选、未打标选项和批量 AI 打标重新列为新增。相关历史细项未完成时归原迭代核实。

本轮新增的是从问题语义中找到现有标签，并让这些结果以明确方式参与检索。

## 2. 输入输出

输入：M01 的原词、规范概念、对象、条件及来源；现有启用标签、说明和层级。

输出：命中标签稳定 ID、可读完整路径、原词对应、匹配方式、歧义、条件来源，以及实际用途（语义条件核对、辅助信号或用户显式标签筛选）。每个硬条件有 condition_id；记录候选的满足／不满足／未知、核对依据及过滤阶段。未匹配词继续保留。

现有标签不以名称替代 ID。历史没有打标来源时标记未采集，不能认定所有旧标签都已人工确认。

## 3. 处理流程

1. 优先按现有名称、别名或已明确维护的同义表达查找。
2. 有必要时用说明和层级生成语义候选，不自动认定近义即等同。
3. 区分明确匹配、多候选歧义和未匹配。
4. 根据任务和条件来源生成检索建议，交 M03／M04 使用。
5. 实际采用结果记录到本轮 Trace，供 M10 审查。

若系统尚无同义词维护能力，可先以小规模受控配置验证，后台独立同义词页面作为后续建议，不列为首期必要功能。

## 4. 核心规则

| 情况 | 默认处理 |
| --- | --- |
| 用户明确要求且确为语义限制 | 记录硬条件并核对资料适用性，不等同于必须有该标签 |
| 用户明确要求只查带某标签的记录 | 按标签成员关系筛选，保留显式标签筛选标识 |
| 从相关上下文明确定义继承 | 在当前话题有效时使用 |
| 模型推断或近义候选 | 优先辅助召回与排序 |
| 资料上未核对的 AI 标签 | 不作为排除其他资料的唯一依据 |
| 没有对应标签 | 保留原 Query 和关键词检索 |

标签逻辑复用已有规则，但任务语义优先。例如“肇东与清徐比较”是两个比较对象，不应变成单篇资料必须同时属于两地。

条件严格时无结果应明确说明；扩大地区或作物范围需说明变化，不静默撤销用户限制。不能仅因为缺少标签就判库中没有资料。

语义条件按共享契约第 4 节执行：先核对访问资格，再合并标签与正文／语义候选。无标签但正文明确符合的资料可核对采用；可靠原文不符合则排除；标签与正文冲突须留痕核对，未解决不称严格匹配；二者均无依据为未知，不猜测满足。未经核对的 AI 标签和模型推断不单独确认适用性。业务条件未知可以保留为候选核对，不能当成满足用户硬条件的证据。

## 5. 后台增量展示

在会话的问题理解区显示原词、候选路径、匹配方法、条件来源和实际过滤用途。不新增完整标签管理页面。

审查者可标映射错误、应有标签、过严或过松筛选及依据；修正当前词典或配置不覆盖历史运行结果。

若未来使用 AGROVOC，只把它作为术语对齐候选；其概念 ID 与本地标签 ID 分开，不自动替换现有分类体系。

## 6. 异常与兼容

标签服务失败时允许按原 Query 检索，并记录降级；资料访问约束不降级。停用标签、非法 ID、维度不一致结果不作为有效筛选。

改名、移动和单多选规则继续执行现有系统校验。全局未打标仍指原产品定义，若停用标签计数政策不明确，仅列待核实，不在本轮擅自调整统计口径。

## 7. 本轮增量验收

| 编号 | 验收内容 |
| --- | --- |
| T01 | 明确同义或名称匹配可定位到稳定标签和完整路径 |
| T02 | 近义多候选可被识别，未匹配不自动创建标签 |
| T03 | 当前与上下文的条件来源可查，推断标签不会造成唯一入口硬过滤 |
| T04 | 两地区比较不会生成错误的单记录且条件 |
| T05 | 无标签和服务失败时仍有可验证的原 Query 检索路径 |
| T06 | 后台显示实际采用条件，历史映射不被新配置覆盖 |
| T07 | 原父子选择、或且规则和全局未打标功能回归保持 |
| T08 | 用户要求玉米案例、正文写玉米但无作物标签时，不在正文召回前排除 |
| T09 | 标签与正文冲突时保留核对记录；条件未知资料不冒充严格匹配 |
| T10 | 用户显式要求标签成员筛选时按标签执行，与一般语义条件分别留痕 |

## 8. 待确认

首批同义表达、歧义处理、匹配方法和词典配置方式由真实问题校准。人工判断过的等同关系与模型推断必须可区分。
