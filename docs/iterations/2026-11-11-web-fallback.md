# 外部搜索仅作为必要解释的兜底

运行记录显示，“土壤模型”“农业模型的发展历程”等基础问题曾因为检索片段缺少完整概述而外搜，单次耗时约 126–139 秒。旧逻辑只检查片段，还把无引用和判断失败视为继续搜索的理由。

调整后的规则：

- 星标完整覆盖时沿用原有直接复用路径。
- 基础概念、历史概述和通用原理已有完整解释时直接返回，不调用外部搜索，也不额外调用模型判断片段是否够用。
- 本地服务不可用或检索失败不能证明内容缺失，不据此搜索。基础解释可先生成明确标记的通用知识说明。
- 其他问题核对现有回答全文与参考内容。只有模型明确返回“不足”且指出具体必要缺口，才允许搜索。不得因为没有引用、片段没有教材定义或缺少用户未问的细节而触发外搜。
- 判断调用限时 10 秒；超时、非法输出或缺口为空时保留现有回答，不搜索。用户说“联网”也不跳过必要性核对。
- 外搜 Query 带入必要缺口，运行记录保存 `external_fallback` 原因；外部回答保留已有内容，仅补充该缺口。原文引用核对继续生效。

验证包含基础问题有/无现有片段、显式联网词、部分专业缺口、判断失败、检索服务失败，以及外部引用与一次修复边界。相关回归 248 项通过。

真实模型独立入口回放“光合作用是什么啊”“土壤模型”“农业模型的发展历程是什么样的”均完成解释，外搜状态为 `not_needed`，没有额外充分性判断。回放包含语义理解与改写、一般知识生成，不包含线上文献检索；10.56–11.94 秒仅是该回放耗时，不代表完整线上请求的固定耗时。结果位于 `/tmp/nitrogen-basic-no-web-replay.json`。
