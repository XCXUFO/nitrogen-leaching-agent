## 已确定的首期策略

- 问题理解与星标匹配采用保守规则和受控词典；不能确认覆盖的候选继续检索。不是通用语义模型，也不自动补齐未知事实。
- 文献先提供手动全文同步；上传、AI 解析和登记不会假称已完成全文索引。当前版本就绪前不采用旧片段；扫描件不提供 OCR。没有向量依赖时允许明确的正文文本索引路径。
- 案例单次最多采用 30 条、材料 JSON 预算 24000 字符。候选全集不受这个预算限制；单条关键材料无法完整采用时如实提示，不破坏表格或更换指定对象。
- 不开放路由、权限、公式或任意 Prompt 文本。表达配置只允许三个已实现枚举，用户本轮要求优先。
- 对照试验借鉴 [CDC 指南（2019 年版）](https://www.cdc.gov/ccindex/pdf/clear-communication-user-guide.pdf) 的表达原则，使用独立编写的中文模板；出处、原件指纹、[使用条件](https://www.cdc.gov/other/agencymaterials.html) 和非背书说明在页面及代码中保留。未安装外部包、未接入在线知识 API/MCP。候选仅在试验入口采用。
- 未完成请求在同一浏览器标签页通过 `sessionStorage` 保留恢复信息，按账号隔离，最多 24 小时；刷新只查询原提交，不自动执行新任务。完成后的普通历史仍沿用内存会话策略。存储不可用时降级为当前页面内恢复。
- 回放使用当前配置和资料，来源为 `test`；原附件凭据或历史输入不足时明确拒绝完整回放，交既有评测入口补原件，不猜测恢复。
- 正式审查只对开发者、领域审核者开放，原评测执行者权限和不可覆盖规则不变。AI 辅助、草稿及冲突不进入有效人工覆盖和正确率；专业忠实性试验结论仅由领域审核者提交。
- 恢复窗口到期只清理可恢复内容及事件，不把原执行成功／失败状态改成“过期”；指标继续保留执行事实。

## 验证与仍需业务验收的事项

完整离线后端回归曾通过 626 项，3 项跳过、1 项 live 排除。其后的受影响范围复验通过 82 项。浏览器覆盖配置、聊天、恢复、导航、正式审查、文献同步和解释对照；累计 54 个不同浏览器用例已验证；临时追踪目录并发清理导致的一次基础设施失败已顺序复验通过。具体最终结果、构建与预览版本见 `verification.json`，逐项需求见 `acceptance-matrix.json`。

另外修复文献慢上传返回时覆盖用户在等待期间刚填写标题的问题；请求期间人工调整的标签也保留。

**M07 的真实农业忠实性和目标用户理解效果仍需人工评价，未伪造专业评审或改善百分比。** 已提供同题固定材料、结果和两类评价入口。其余模块为本轮工程交付与自动化验收，最终业务签收仍应按 V0.3 的真实联合样本执行；复杂表达、未覆盖同义词和真实资料分布需继续校准。

没有自动新增正式星标、文献、案例或专业人工结论；没有用模型或程序检查替代领域审核。
