# 本轮问题决定回答语言

## 规则与实现

- 明确的英文问题使用英文回答，包含标题、解释、追问、澄清和领域拒答。
- 中文、中英混合，以及仅有字段名、缩写、数字或符号等不明确的输入优先中文。
- 有正文和明确问题标签时，根据实际问题判断；正文、文件名和上一轮回复的语言不替代本轮判断。
- 每轮重新判断，因此可以在同一会话内切换语言。文件名、字段、单位、引用及必要的原文引句保持来源身份。

新增统一语言上下文，并加入共享表达提示。文件统计、寒暄、能力说明、领域拒答和常见缺少附件提示支持直接使用英文，文件计算不为翻译额外调用模型。表格语法增加有限的英文极值措辞和英文追问，不扩大计算能力。

最终回答、分节和警告都接受语言校验。发现错误语言时，只翻译不合规的部分；数值、单元格、文件标识、引用等先替换为保护标记，返回后校验并恢复。翻译丢失事实标记、增加数字或仍使用错误语言时，不将其作为成功回答返回。校验和修复用量进入轨迹。

真实初测发现：中英文材料混用时，模型会在 `winter wheat` 后保留 `冬小麦`，翻译也可能照抄。已要求英文回答翻译普通作物名称并删除重复中文括注，保留严格校验；独立真实模型诊断确认此题可正常返回英文。
