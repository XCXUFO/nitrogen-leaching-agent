# M02｜星标问题聊天优先匹配 PRD（增量修订）

版本：V0.3｜日期：2026-10-17｜状态：审查修订，待开发验收

V0.3 补齐开发前审查 R01—R05；跨模块规则统一引用[运行、检索与审查契约](14_跨模块运行与审查契约.md)。本次是文档修订，不表示应用功能已实现或验收。

## 1. 已有基础与本轮变化

星标问题 V0.2（B3）已经定义后台完整问题、选填答案、新增、编辑、换行文本和保存持久化；能力盘点 B4 确认相关维护入口已存在。本轮不重建管理页，也不重新要求首批录入。

25 条专业问题、排除 7 条非专业问题属于原录入范围；完成情况以现有库和原验收记录为准。没有完整问答清单不妨碍编写本轮链路需求，也不构成重复迁移的理由。

本轮仅新增：聊天匹配、答案覆盖判断、适用内容复用，以及与后续检索／Skill 的衔接。辅助搜索、无答案筛选等上一版助手建议不列为本轮必做。

## 2. 目标与入口

对适用的专业知识或案例子问题，先查看已有问答能否回答；用户不需要手动进入星标页面。明确文件计算、能力咨询等分支不强制等待无关匹配。

后台维护仍沿用原 V0.2：问题必填、答案可空，无情境还原、答案审核、发布或完整问答版本管理。原稿排除的语义匹配在本轮作为新增能力单独估算，不能混入原管理页验收。

## 3. 流程与匹配规则

M01 输出问题和子任务 → 查找候选问答 → 检查含义、条件和答案覆盖 → 返回可用部分和未覆盖任务 → M06 直接组织或继续检索。

| 结果 | 判定 | 行为 |
| --- | --- | --- |
| 完整覆盖且适用 | 问题含义一致，答案足够，关键条件不冲突 | 依据已有答案组织，必要时通俗解释 |
| 部分覆盖 | 仅能回答某个子问题或部分内容 | 保留可用部分，对剩余任务继续处理 |
| 命中但无答案 | 问题相符，人工答案为空或只有空白 | 继续检索，不能直接以暂无答案终止 |
| 相近但不适用 | 作物、阶段、单位、口径或任务不同 | 不套用答案，记录原因 |
| 未命中 | 没有可靠候选 | 继续原资料和能力路径 |
| 匹配失败 | 服务或契约异常 | 降级到原链路，后台记失败 |

相似度只帮助选候选，不能替代适用性判断。当前答案情境不完整时，不假定材料中未出现的条件。阈值、检索方式和候选数用真实同义与近似反例校准，不预写固定参数。

## 4. 部分复用与回答

例如星标答案解释了折氮量，而用户同时询问具体田块施肥量，只复用概念部分。未覆盖部分需要相应依据和条件，不能由原答案扩写。

原人工答案继续保留原意；可整理排版或补必要术语说明，不改变数字、单位、条件及确定程度。补充背景与原答案内容可区分，不能伪装为材料原有内容。

对客可使用“参考已有专业问答”，不直接标成经过审核的标准答案。与其他证据冲突时保留冲突并供后台审查，不设置无条件优先的权威等级。

## 5. 后台新增可见信息

在现有会话审查中增加候选问答、覆盖结果、采用部分、未采用原因和后续路径。内部稳定记录 ID 用于定位，公众不需看到。

每次运行保留当时采用内容的可追溯标识或必要快照。维护页修改后，新运行读取新内容；历史回答和运行事实不重写。这是运行追溯要求，不新增独立问答版本平台。

覆盖记录绑定当前 run_id、turn_id、subtask_id，逐项保存采用内容、来源指纹和未覆盖任务；后续步骤引用稳定子任务标识，不按答案段落位置推断。网络重发读取原匹配事实，主动重跑另存新快照；运行与幂等规则见共享契约第 2 节。

## 6. 异常与回归保护

匹配失败、未命中、命中空答案分别记录。原星标新增编辑、选填答案、失败保留输入和问题答案一一对应作为回归保护，不计入本轮新功能量。

不自动把新问题、即时回答写入星标库，不自动向 Agent 发问，不自动创建评测任务。

## 7. 本轮增量验收

| 编号 | 验收内容 |
| --- | --- |
| S01 | 同义问题且答案适用时复用，条件相近但冲突时不套用 |
| S02 | 命中空答案仍进入后续能力，空值不被当作终止答案 |
| S03 | 复合问题只复用已覆盖部分，剩余任务确实被处理 |
| S04 | 匹配服务失败进入原链路，后台能区分失败与未命中 |
| S05 | 后台可定位候选、采用内容、原因和后续调用 |
| S06 | 原管理功能回归通过，修改后新运行使用最新内容，历史不改变 |

## 8. 依赖与待确认

依赖 M01、现有星标数据、M06 和 M10。需补充真实校准样本；首批问答的实际数量与对应关系可在联调时核对，不设为重新建设管理模块的前提。
