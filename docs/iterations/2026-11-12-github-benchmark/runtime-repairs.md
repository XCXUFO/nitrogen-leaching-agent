# 原运行异常重测与 CPU 推理修复

## 基线与重跑范围

此前第一批有 19 轮超时，多轮批次有 16 轮超时、3 轮内部异常。新的重跑批次保留原问题、真实附件和实际对话历史，不覆盖基线，也不修改人工审核结论。

选择全部失败轮次所在的 25 组；多轮组从首轮完整重放，合计 44 轮。最终批次：`backend/var/eval/failed-runs-retest-final-20261112/`。

## CPU 推理瓶颈

本机有 8 个可用 CPU，使用本地 BGE 大模型嵌入和重排。直接测量确认重排消耗大量时间。不能把所有超时都归于同一处：原轨迹另有语义理解、概念问答等阶段的超时，重跑后继续区分。

针对同一个进程、同样的四段长文本、单线程、长度上限 512、批次大小 2 的对照：FP32 9.84 秒，动态 INT8 3.37 秒。另一个包含相关农业文本和无关文本的小型检查中，两种精度均把直接相关文本排在前面；这不构成完整的检索质量评测。INT8 会改变近似分数和部分排序，仍需要专业评审回答质量。

本地运行配置显式启用：

```text
RAG_RERANKER_CPU_QUANTIZATION=int8
RAG_RERANKER_MAX_LENGTH=512
RAG_RERANKER_BATCH_SIZE=2
RAG_CPU_THREADS=2
```

INT8 默认关闭，可通过配置回退。保持嵌入模型、候选数量、最终返回数量、筛选、数值加权、证据身份及原始片段内容。重排评分的输入长度有上限，不能将其当成对任意长文本都无影响；给回答模型的原片段不因重排而截断。

兼容已安装的 sentence-transformers 新版只读 `model` 属性，以及旧版直接保存 transformer 的结构；测试验证量化替换实际 transformer，不误增一个破坏输入结构的流水线阶段。没有安装或升级依赖。量化在新创建且独占的模型上原地进行，避免启动时额外复制一份完整 FP32 权重；这不会增加同时运行的模型实例。

性能探针和结果位于 `backend/var/eval/retrieval-performance-20261112/`。临时探针的错误同样保留，不作为成功或质量证据。

## 用户记录与多轮更正

实测前的回归复现了两个独立问题：明确粘贴的合成观测记录仍被当成缺附件；试验条件被当成普通文献问题，更正和最终汇总不能稳定沿用原记录。

识别带正文的观测记录、试验条件、试验方案记录，以及明确要求复述且实际包含数字的农田试验记录。缺少正文、仅提供链接或询问记录概念，不算已提供数据。单轮源文直接进入已有用户文本问答，不依赖文献、案例库或虚构文件证据。

多轮仅承接已确认的用户原文状态，按更正更新指定对象并保留其他条件；冒号不再使更正丢掉上下文。无附件的给定数据最大值可在原文基础上回答；显式文件、文献、新案例或换话题仍保留各自路径。领域外晚餐问题仍拒答，返回原试验时可恢复记录。提示允许基于明确给出的等量分次进行算术，但不能假设效率系数或虚构实测效果。

最终合并相关回归 475 项通过，1 项主动开启的真实模型测试跳过；记录原文路由、文件文档、语言切换、领域边界及重排均在覆盖范围内。JUnit：`backend/var/eval/final-runtime-repair-20261112-tests.xml`。

## 批次中断与评测脚本

原重跑批次已保存 15 个正常完成的结果。运行期间本地后端被另一轮修复重启，登录失效、服务配置版本改变；原批次和中断记录全部保留，不能把它当作同一版本的完整复测。

评测脚本现在在 HTTP 401 时串行刷新登录一次，重发相同请求体及稳定 request_id，不新增一轮对话，不记录密码或 token。刷新后仍失败即停止当前操作，避免无限重试。新增测试验证请求体保持一致、持续拒绝时只重试一次，以及并发失败共享续期。恢复执行前仍核对配置，版本变化要求另建批次。

最终完整重跑另建批次，保存加载前代码快照、初始配置和结束配置；结果按每轮实际 trace 的版本核对。

## 启动检查的更正

一次沙箱内进程检查未看到外部后端，曾误判为进程退出。外部进程检查确认原 PID 仍存活，服务随后就绪；没有证据证明发生了 OOM 终止。缺失实例恢复入口的重复进程检查拒绝了额外启动。最终仅在确认活动请求为 0 后正常重启并保留原环境。量化峰值内存优化是对明确的完整模型复制开销做修复，不把它描述成已证实的崩溃根因。

## 完整重放的结果

最终完整批次 `failed-runs-retest-final-20261112` 的 25 组、44 轮全部正常完成，覆盖原 38 个失败轮次，38/38 恢复；没有超时或内部错误。44 个唯一 Run 的结果和轨迹均已持久化。配置前后相同，全部 trace 均为 `local-unversioned:360a3ebda1353791`；44/44 语言检查通过。延迟中位数5.89秒，最长92.23秒。

这不是44个内容全对：灌水计算有多余效率情景，专业回答出现尿素态氮迁移表述错误和重复引用；MT-Bench“后一原因”在实际多候选回答后被澄清，尚未完成参考目标。详见批次 `quality-notes.md` 和逐题初评。

真实多轮检查还暴露了三个可复现流程问题：否定的“不评价效果”触发效果核验；用户原文被空案例库证据覆盖检查标成缺依据；语义改写给更正问题附加“玉米是什么”等新问题。后续已修复：效果意图忽略相应否定短语，库内对象覆盖仅核对实际库内材料，已确认用户原文追问直接使用原始问题与独立保存的原文上下文。补充遵循“只复述/更正/汇总/算术”的表达范围，不主动要求未问的效果条件。

新版对受影响的4组16轮从首轮重放，另跑25轮语言和12轮边界/误拒对照；均另建批次，保留完整44轮旧版结果。
