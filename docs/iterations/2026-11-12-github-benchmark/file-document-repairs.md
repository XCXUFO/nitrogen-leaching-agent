# 文件与文档问答异常修复

## 修复范围

以此前多轮实测的 MT-04、MT-06、MT-09 为回归对象，保留原批次和原回答，不修改人工审核结论。

1. **文本附件 HTTP 500**：旧版 `file_id` 未调用文档提取接口，导致文本报告进入依赖 `columns` 的表格分析器。现在两种附件参数都会加载当前授权附件中的文档；文档问题进入资料问答。表格分析器另加文档类型保护。
2. **正常统计措辞反复澄清**：允许“本次上传氮平衡表”“汇总”“单元格”等不改变计算范围的措辞。新版多文件入口先校验完整的单字段问题，避免将逗号后的单位、单元格要求错误拆成第二项计算。继续拒绝未经支持的时间筛选、浓度换算和附加专业判断。数值、日序的单元格位置直接显示在回答中。
3. **文档核对等待无关文献检索**：确认是在询问上传文档时，直接选择文档片段生成回答，跳过整个本地向量库和外部检索。记录实际供给片段和来源范围。连续追问只在附件内容哈希不变时继承此范围；明确询问文献会回到文献路径。提示要求缺少观测、产量变化、统计检验时说明缺口，不补造实测值。

这些修复解决上传资料路径的异常与无关检索，并未证明通用文献检索的全部超时问题已经解决。
