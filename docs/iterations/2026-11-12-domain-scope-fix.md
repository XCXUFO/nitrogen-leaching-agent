# 农业相关问题误拒答修正

## 问题与原因

- 原 Run `52e6f63f-b467-460f-9f30-1ffec7b59015`：询问亚马孙耕作中土壤肥力与杂草问题，误判为领域外。规则先按分号拆开回答约束与正文；语义改写虽被条件检查驳回，`outside` 仍直接进入拒答路由。
- 原 Run `75561934-6af5-4303-aec0-27b05a28fc9a`、`694f6d50-e503-45e2-a372-7fb96624cd69`：植物产氧及呼吸作用追问被要求与氮淋失直接相关，服务领域解释过窄；英文基础概念识别也不完整。

## 修正

1. 将显式粘贴的正文、回答限制与问题保留为完整任务，标记 `user_text`。正文与问题不因分号、并列词拆开；文本解读始终收到原文。
2. 对粘贴资料、改写被拒或含农业主题线索的 `outside` 判定，使用原问题独立复核。关键词只触发复核，不直接授权回答；复核不可用时降级为 `unknown`，回答仍受领域规则约束。记录复核结果、最终领域及实际模型用量。
3. 明确植物光合作用、产氧、呼吸作用等农业基础知识属于服务范围，支持中英文。历史拒答不构成下一轮继续拒答的依据。
4. 粘贴资料的问题交给现有文本解读能力；显式问题标签中的实际需求优先于正文中的话题、案例或无关词语。仅依据资料的任务不补入通用知识。
5. 补全中英文基础植物概念路由，保留定量研究、文献、文件等专业任务优先级。
